# 王都餐厅

> 分包 `restaurant`。定位：农场 → 加工屋 → 牧场 → 餐厅这条产业链的高价出口。

## 玩法

| 页签 | 玩法 |
|---|---|
| 备料台 | 5×3 备料台 + 2 个 3×3 灶台；2 件相邻、3 件三连/L、4 件方块/T |
| 点菜 | 成品柜上菜，菜价 + 繁荣度；每日 8 道领 150 币 +3 繁荣 |
| 营业 | 无固定时长；客人 1–5 道订单、清水 + 已解锁原材料、6 格成品柜、品质计价 |

- 配方表：`data/combos.ts`（56 条，含半成品链与 4 输入深链菜）。
- 备料台：`systems/counter.ts`（每格一件）。
- 灶台：`systems/stove.ts`（图案匹配 / 烹饪 / 焦糊品质）。
- 建议：`systems/advice.ts` + `systems/context-advice.ts`（拖拽/点选上下文 → 建议与空灶 ghost）。
- 交互拆分：`game-drop.ts`（拖放路由）、`game-serve.ts`（上菜反馈）。
- 营业：`systems/shift.ts`（不读写 `pantry`；打烊/退出结算）。
- 存档：`systems/save.ts` v6，保存备料台、灶台、已发现配方、每日点菜目标与完美打烊次数。
- 视图：`view/restaurant-view.ts` + `kitchen-page/shift-page/order-view/overlay-view/counter/stove/suggestion/shift/supply-rail` 模块。

## 关键规则

- 灶台只在完整图案出现时判定配方；2/3/4 件不会互相退回；
- 出锅后 10–14 秒内是 100% 品质，之后每 5 秒降一档到 75/50/25%，焦炭不能上菜；
- 成品柜锁定品质并暂停焦糊；营业里可拖回灶台当深链输入，品质不继承；
- 焦炭清掉后可回收 1 份饲料（营业在打烊时入仓库）；
- 营业只有清水；crop/flower/ranch 原材料第一次收获后永久解锁，供应轨横向滑动、未解锁灰显；半成品和成菜必须现做；
- 成品只在本局有效；打烊进入「打烊中」，停止来客并服务完当前客人；完美打烊不罚款，未服务完按 30% 未上菜价值罚款，净收入可为负但王都币最低 0；
- 缺料不再一键补齐：去农场/牧场/加工屋生产。
