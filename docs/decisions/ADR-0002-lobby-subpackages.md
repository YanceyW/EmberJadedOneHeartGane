# ADR-0002：大厅 + 普通分包

- 状态：已接受
- 日期：2026-02

## 背景

主包 ≤4MB，全部 ≤30MB。
需要装多款游戏，且用户不该一次下载全部。

## 决策

- 主包：大厅 + core + shared + 启动资源；
- 每款游戏一个**普通分包**；
- 不使用独立分包；
- 分包入口 `games/<id>/game.js` 注册 `GameDefinition`；
- 大厅按需 `wx.loadSubpackage`；
- 空闲预下载下一款（失败静默）。

## 后果

正面：

- 主包小；
- 按需加载；
- 共享主包代码；
- 分包可依赖主包。

负面：

- 分包加载后常驻，不能卸载；
- 需要内存预算；
- 分包入口需自行注册。

## 约束

- 主包不得 require 分包；
- 单款 ≤2MB；
- 分包资源退出时释放（代码常驻）。
