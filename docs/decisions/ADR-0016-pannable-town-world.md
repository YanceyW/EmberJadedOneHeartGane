# ADR-0016：大厅改为平铺可平移王都世界

- 状态：已接受
- 日期：2026-11

## 背景

ADR-0013 的大厅是固定轴测、单屏构图。用户希望首页更完整、更像一座城，并询问左右平移与缩放能否支撑后续扩展。

固定轴测的菱形投影会把新建筑挤在中央，且无法自然地向左右长街扩展；同时「漂浮在云海上的球」不利于表现平铺街道、花圃和远景。

## 决策

- 大厅改为**平铺地面 + 宽世界**：世界宽 1500 设计像素，默认视口 750；
- 世界坐标以屏幕中心为 0，默认相机下 `screenX = worldX + viewWidth / 2`；
- 相机支持：
  - 单指左右拖动；
  - 双指捏合缩放 0.85–1.2，缩放锚点在捏合中心；
  - 水平 clamp 到世界边界，不做垂直平移、旋转或透视 3D；
- 地面、天空、建筑按昼夜阶段烘焙；建筑按深度排序，前景（花车/长椅/路灯/花圃）以 1.04 倍相机位移制造轻微视差；
- 保留四个初始场馆的相对位置，`futureAnchors` 预留在东西两侧（西街/东街）；
- 点击/命中测试统一走世界坐标，默认相机下旧冒烟点击点 (162, 700) 仍命中三消。

## 后果

正面：

- 首页从「一张卡片」变成可以逛的街区，左右平移为后续场馆留出空间；
- 平铺地面更容易叠加道路、花圃、居民和远景；
- 静态层烘焙 + 相机裁剪，平移不会触发重新生成。

负面：

- 取代 ADR-0013 的固定轴测大厅方案；
- 需要维护相机边界、世界/屏幕坐标转换和烘焙画布尺寸；
- 窄屏 + 高缩放时可见范围变小，装饰密度需要按视口控制。

## 约束

- 不做垂直平移、旋转、自由 3D；
- 相机必须在 `cameraBounds` 内；
- 新场馆只能加到 `town-layout` 的世界坐标表，不得在大厅外另建一套相机；
- 低端机可关闭场景动效，但平移/缩放本身必须可用。
