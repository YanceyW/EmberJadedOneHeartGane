# ADR-0026：营业食材解锁、横向供应轨与打烊中

- 日期：2026-11-27
- 状态：已接受
- 相关：ADR-0023（仓库与餐厅三线）、ADR-0024（餐厅组合台与牧场）、ADR-0025（3×3 灶眼与无时限营业）

## 背景

ADR-0025 之后，营业仍是「12 种基础农产 + 蛋奶」的硬编码供应：

1. 农场 18 种作物、花园 9 种花卉、牧场 4 种产物没有完整进入营业，部分食材只在单一玩法里有用途；
2. 7 种原材料（白萝卜、黄瓜、雏菊、郁金香、向日葵、风信子、荷花）没有餐厅配方；
3. 供应只有 7×2 固定托盘，食材变多后需要分页；
4. 有未上菜客人时点「打烊」会弹确认，而无时限营业几乎一直有客人，确认会变成无意义点击；
5. 净收入被强制不低于 0，罚款无法完整体现经营失败。

## 选项

1. 继续硬编码基础材料，只给新食材加配方；
2. 所有食材都无限供应；
3. 只让原材料按「曾经在农牧场收获过」解锁，半成品/成菜仍必须现做；
4. 打烊直接结算，或保留确认弹窗；
5. 打烊进入「打烊中」，停止新增客人并服务完当前客人；净收入允许为负，钱包最低 0。

## 决策

采用 3 + 5，并配套：

- profile v8 新增 `ingredientUnlocks`，`addPantry()` 与农牧场首次收获写入；旧存档从 `pantry` 播种，已解锁牧场方块的旧档补 `egg`/`milk`；
- 营业供应 = 清水 + 已解锁 crop/flower/ranch；processed/drink/dish 不进无限供应；
- 供应轨改为两行 × 7 列横向滑动：已解锁在前，未解锁灰显加锁排在后面；横向拖动滚动，向备料台/灶台拖动才拿料；
- 新增萝卜糕、拍黄瓜与 5 款花茶，保证所有 raw 原材料至少有一条餐厅用途；
- 打烊进入 `closing`，不再新增客人；客人清空后自动结算，无流失为「完美打烊」；
- 打烊中流失按未上菜总价 30% 罚款；直接退出追加剩余客人赔偿；
- `netRevenue = revenue - penalty` 可以为负；结算只应用一次，钱包最低扣到 0；
- 餐厅存档 v6 增加 `perfectCloses`；每日点菜目标改为 150 王都币 +3 繁荣。

## 后果

- 食材解锁成为跨农场/花园/牧场/餐厅的长期目标，卖光库存不会回退；
- 营业供应随玩家进度增长，但半成品和成菜仍必须现做，不能绕过灶台；
- 需要维护 profile 与餐厅两套 schema 迁移；
- 供应轨增加横向手势，需与食材拖拽做轴向区分；
- 罚款可以造成负净收入，但不会让王都币为负；
- 新配方必须继续满足「菜价 > 食材、仓卖 < 食材、全采购不划算」的经济约束。
