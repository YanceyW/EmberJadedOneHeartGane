# ADR-0013：大厅固定轴测 2.5D 王都

- 状态：已被 ADR-0016 取代（大厅改为平铺可平移世界）
- 日期：2026-11

## 背景

大厅原本是四张 2.5D 卡片 + 平面背景。希望改成更完整的「王都街区」：有喷泉、道路、场馆建筑、国王王后与环境居民，同时保留竖屏单手操作和低包体。

用户希望参考暗黑破坏神 4 的斜俯视视角，但美术基调仍是奶油童话 + Q 版，不做暗黑/写实/恐怖。

## 决策

- 大厅使用**固定轴测投影**（非透视相机、不可旋转/自由缩放）：
  - `screenX = originX + (gx - gy) * 82`
  - `screenY = originY + (gx + gy) * 42`
- 建筑围绕中央喷泉摆成菱形；四栋建筑使用屏幕包围盒做命中，不使用 3D 拾取。
- 玩法层（三消棋盘）继续使用正视矩形网格，**不引入等距玩法坐标**。
- 动态表现只做：昼夜调色、云海漂移、喷泉、招牌摆动、居民走动、花瓣/萤火虫、建设等级变化。
- 低端机/减少动效关闭居民、花瓣、萤火虫和招牌摆动。

## 后果

- 大厅更像一个真正的王都，但每个建筑需要独立矢量和命中盒；
- 建筑遮挡通过深度排序（`base.y`）+ 前向命中优先解决；
- 后续新增场馆时只需扩展 `town-layout` 的建筑表；
- 与 ADR-0011 不冲突：ADR-0011 约束的是玩法网格，本 ADR 只改大厅表现层。

## 约束

- 不做可旋转/自由缩放的 3D；
- 不每帧使用 `shadowBlur`；
- 建筑/道路/装饰全部代码绘制，不引入大图；
- 重要按钮和建筑避开微信原生胶囊区域。
