# ADR-0004：程序化 + 位图混合

- 状态：已接受
- 日期：2026-02

## 背景

包体有限，但需要统一、好看、可扩展的视觉。
纯位图包体大；纯程序化容易变几何 Demo 且卡顿。

## 决策

混合：

- UI/图标/背景/图案/简单方块：程序化 + 缓存；
- 角色/关键图/复杂材质：位图；
- 关卡/订单/花纹/花色：种子化生成；
- 静态层离屏缓存，每帧只 drawImage；
- 程序化缓存 LRU + 引用计数；
- 超预算改预烘焙。

## 后果

正面：

- 包体小；
- 风格统一；
- 内容可无限生成；
- 可复现。

负面：

- 需要缓存/性能预算；
- 生成代码复杂度；
- 低端机需降级。

## 约束

- 禁止每帧复杂路径/全屏 shader；
- 必须 seeded；
- 单屏 <50ms；
- 缓存 ≤32MB/游戏。
