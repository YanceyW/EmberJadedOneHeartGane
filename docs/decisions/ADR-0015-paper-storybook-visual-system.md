# ADR-0015：奶油纸雕童话视觉系统

- 状态：已接受
- 日期：2026-11

## 背景

大厅旧版是「四张卡片 + 平面背景」，用户反馈不够好看，希望首页有明确的视觉风格、Q 版可爱画风，并愿意用 CPU/GPU 算力换取素材空间、粒子和手绘感。

约束仍然是单运行时 Canvas 2D、无 bundler、主包 ≤ 3MB、全竖屏、休闲品类；不能为了视觉引入新引擎、WebGL 主渲染或大图资产。

## 选项

1. **A 水彩绘本**：纸张纹理 + 水彩晕染边缘，柔和但轮廓容易糊；
2. **B 奶油纸雕**：厚暖描边 + 平涂三阶色 + 轻纸纹 + 贴纸/叠纸阴影，轮廓清楚、Q 版稳定；
3. **C 干净矢量**：最省算力，但偏通用 App 插画，缺少手作温度；
4. **D 混合**：背景水彩、前景纸雕，风格容易分裂。

## 决策

选 **B 奶油纸雕 + Q 版童话**，覆盖大厅、弹窗、按钮、角色与粒子：

- 新增 `shared/design-system/paint.ts`：抖动路径、纸纹、柔和阴影、墨线、圆角路径等程序化笔刷；
- 新增 `shared/design-system/paper-ui.ts`：纸面板、贴纸按钮、分段标签、开关、胶带便签、虚线分隔；
- 角色改为 2 头身 Q 版：大眼睛、圆手圆脚、腮红、换装大色块；
- 静态天空/地面/建筑按昼夜阶段烘焙到离屏画布，运行时只 `drawImage`；
- 环境粒子（花瓣、落叶、喷泉水花、烟、萤火虫、星光）走预烘焙图集 + SoA 池，包体 0 字节；
- 所有颜色/圆角/字号/动效仍从 design tokens 取，不新增游离色值。

## 后果

正面：

- 首页有了统一、可辨识的「纸雕童话」气质；
- 轮廓清楚，缩放到 0.85–1.2 仍可读；
- 静态层烘焙后，运行时开销主要是合成与少量动态叠加；
- 角色/建筑/UI 共用同一套笔刷，四款游戏并排更像同一个世界。

负面：

- 程序化路径比纯贴图多少量 CPU 开销，低端机需要减少装饰与粒子；
- 纸纹、抖动描边需要固定 seed，避免每帧变化；
- 复杂光影/写实材质仍然做不了。

## 约束

- 不引入 Unity/Cocos/Phaser/PixiJS、WebGL 主渲染、bundler；
- 不把 AI 原图、PSD、未压缩音频打进包；
- 纸雕不是「描边滤镜」：静态层必须烘焙，禁止每帧重建渐变/`shadowBlur`；
- 低端机/减少动效关闭环境粒子、招牌摆动、场景动效；
- 视觉参考只吸收「纸雕/绘本」的通用语言，不复制具体作品或角色。
