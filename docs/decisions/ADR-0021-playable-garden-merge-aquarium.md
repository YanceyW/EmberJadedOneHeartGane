# ADR-0021：花园/加工屋/水族馆先做可玩原型

- 状态：已接受
- 日期：2026-11

## 背景

用户要求「将剩下的几个也都做出个能跑的样子」，并强调统一画风、王都币能消费也能赚。

此前花园、加工屋、水族馆只有设计文档与「即将开放」占位；如果直接做完整遗传/繁育/造景系统，周期长且无法尽快验证经济循环。

## 决策

先做**单局可玩、可存档、能赚/能花王都币**的垂直原型：

- **花园**：6 块花圃、4 种花（45/75/120/180 秒）、浇水缩短 35%、花单/卖花；`save:garden`。
- **加工屋**：5×5 加工台、莓果→果酱→蛋糕→宴席、进货 6 币、加工单/卖成品；`save:merge`；正式名称由「合成屋」改为「加工屋」。
- **水族馆**：6 个鱼位、3 种鱼、喂食 3 次成熟、成熟鱼每 15 秒产 1 泡泡币（单条上限 20）、访客订单；`save:aquarium`。
- 三者全部使用 `paper-ui` / design tokens / 现有角色与粒子语言；不新增图片资产。
- 每个游戏退出时向 `leaderboard` 提交本馆分数（花园/加工屋/水族馆各自一个 `gameId`）。

暂不做：花园遗传/繁育、加工屋店铺装饰、水族馆鱼纹/繁育/造景、双人模式；这些保留在设计文档中作为后续迭代。

## 后果

- 五个场馆全部可进入、可游玩、可产出/消耗王都币；
- 分包体积极小（每个约 0.02–0.03MB）；
- 经济循环可在真机验证：三消赚币 → 各馆买种子/鱼/进货 → 订单/卖成品回币 → 小铺买外观/方块皮肤；
- 后续扩展遗传/繁育时，存档字段可增量迁移。

## 约束

- 不抽卡、不内购、不做陌生人社交；
- 离线收益有上限（水族馆单鱼 20 币、作物不死亡）；
- 所有随机使用 seeded RNG（加工屋进货使用 `ctx.rng`）；
- 不引入新运行时或图片资产。
