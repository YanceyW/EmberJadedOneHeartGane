# ADR-0017：大厅天气、节日风格与可切换建设等级

- 状态：已接受
- 日期：2026-11

## 背景

用户希望首页有天气、节假日风格，并能用王都币购买切换；同时已购买的建设等级也应该可以切换回低等级，因为低等级的效果可能更符合个人喜好。

约束：所有内容必须是纯外观，不影响分数/掉落/公平；天气免费，节日风格用王都币购买；天气与风格可组合。

## 决策

### 天气（免费）

- `clear / rain / snow / petals` 四种；
- 纯前景覆盖层，画在场景之上、UI 之下；
- 不改变建筑烘焙，不改变命中；
- 低画质减少粒子，减少动效只保留色调。

### 节日风格（王都币）

- 首批：`classic`（免费）、`spring`、`lantern`、`harvest`、`frost`；
- 风格改变 `TOWN_PHASES` 的部分天空/草地/道路/屋顶颜色，并追加轻量装饰；
- 风格切换时使 `TownArt` 缓存失效并重烘焙；
- 风格不影响玩法、经济产出或建筑解锁。

### 建设等级

- `Profile.cosmetics.buildMax` 记录已购买最高等级；
- `Profile.cosmetics.build` 记录当前展示等级；
- 购买升级提升 `buildMax` 并自动切到新等级；
- 玩家可以在 `0..buildMax` 之间免费切换；
- 喷泉/街灯/花圃都按当前展示等级绘制。

## 后果

- 玩家可以组合天气 + 节日 + 建设等级，得到更多外观；
- 存档从 v3 迁移到 v4，旧档 `buildMax = build`；
- 风格切换会重烘焙静态层，频率低，可接受；
- 天气每帧只画少量覆盖粒子，受画质预算限制。

## 约束

- 不卖数值、不卖爆率、不做真实货币；
- 不引入天气/节日专属大图资产；
- 不在天气层上做点击命中；
- 低端机/减少动效必须可关闭。
