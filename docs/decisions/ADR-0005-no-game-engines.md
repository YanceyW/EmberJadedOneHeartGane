# ADR-0005：不引入 Unity/Cocos/Phaser/Pixi

- 状态：已接受
- 日期：2026-02

## 背景

用户有 Unity 经验，问是否每款游戏可用不同引擎。
但合集需要共享主包、统一风格、可控包体。

## 决策

- 合集内不引入 Unity/Cocos/Phaser/Pixi；
- 只用 TypeScript + Canvas 2D + 自研运行时；
- 如果未来某款重度游戏确实需要引擎，**只做独立小游戏**，不放进合集主包。

## 后果

正面：

- 包体可控；
- 无重复运行时；
- 共享/统一；
- 调试简单。

负面：

- 失去引擎编辑器/生态；
- 需要自己实现基础能力；
- 复杂 3D 不做。

## 约束

- 任何“换引擎”提议必须先写新 ADR；
- 不允许悄悄引入引擎依赖。
