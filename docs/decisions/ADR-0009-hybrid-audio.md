# ADR-0009：音效混合方案（合成 SFX + 文件 BGM）

- 状态：已接受
- 日期：2026-11

## 背景

项目此前**完全没有声音**（`AudioService` 是空壳）。需要一套统一、省包体、可变调的反馈音。

## 选项

1. 全文件：质量稳，但每款游戏 10+ 个 SFX 会吃掉几十 KB，且无法按连击变调；
2. 全合成：包体 0，但 BGM 用振荡器写会非常单调；
3. 混合：SFX 合成 + BGM 文件。

## 决策

选 **3**：

- SFX 用 `wx.createWebAudioContext()` 实时合成（基础库 2.19+）；
- BGM 用本地模型（ACE-Step）生成 30–45s 循环，96kbps 单声道 mp3；
- 大厅 BGM 进主包，各游戏 BGM 进各自分包；
- 无 WebAudio 能力时静默降级，BGM 仍可播。

## 后果

正面：SFX 0 字节、音色天然统一、可按连击升调；BGM 质量可控。

负面：合成音偏「电子味」，需要靠低通 + 短包络 + 低音量收敛；
需要维护一套合成配方。

## 约束

- 同屏并发声上限按设备档位（6/5/3）；
- 首次触摸后必须 `unlock()`；
- 尊重系统静音（`obeyMuteSwitch`）；
- BGM 生成记录（模型/prompt/日期）留在 `docs/asset-library.md`。
