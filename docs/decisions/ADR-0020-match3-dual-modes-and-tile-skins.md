# ADR-0020：三消双模式、方块皮肤商店与分模式排行榜

- 状态：已接受（无尽模式的 30 步上限已由 ADR-0022 改为不限步数）
- 日期：2026-11

## 背景

三消原本有「闯关 + 每日挑战」两套入口，但每日挑战与闯关共用计时/目标逻辑，玩家实际只感知到一种玩法；同时方块外观按关卡自动切换，玩家没有购买/选择动力。

用户要求：

1. 三消只保留**闯关**和**无时间限制**两种模式；
2. 联动方块放到王都小铺卖；
3. 排行榜拆成两个子项。

## 决策

- 移除每日挑战模式（`data/daily.ts`、HUD「每日」入口、每日存档字段）。
- 模式：
  - **闯关**：180 秒、10 关、目标分 1500–4200；达标锁 1 星并解锁，继续冲 2/3 星。
  - **无时间限制**：30 步、不计时；每成功交换扣 1 步；步数用完结算。给一个明确终点，避免无限刷与排行榜不可比。
- 方块皮肤：
  - 皮肤目录移到 `src/shared/content/tile-skins.ts`，三套：甜品屋（免费）/ 农场 180 / 王都食集 260；
  - 购买与装备走 `profile.cosmetics.tileStyle/ownedTiles`（Profile v5）；
  - 闯关与无尽共用当前装备；只换外观，不改规则/难度。
- 排行榜：
  - `match3-campaign` 与 `match3-endless` 两个 `gameId`；云函数按 id 分开存储；
  - 大厅排行榜加入这两个子项，其余场馆各一项。
- 存档：
  - Match3Save v4：`bestScore`、`endlessBest`、`wins`、`unlockedLevel`、`stars`；
  - 旧 v1–v3 的每日字段在迁移时丢弃。

## 后果

- 每日挑战相关内容从代码/文档移除，降低维护面；
- 方块皮肤成为王都币的新消耗点，且不影响公平；
- 两个排行榜分别反映「关卡进度」与「单局极限」，不会混在一起；
- 每日挑战的「固定棋盘」体验暂时消失；如未来需要，可做独立活动，不再作为常驻模式；
- 无尽模式 30 步需要观察真机数据，后续可调步数或奖励公式。

## 约束

- 不卖时间、步数、分数、道具；
- 皮肤价格与数值无关；
- 排行榜只提交本模式成绩；
- 不恢复每日强制打卡。
