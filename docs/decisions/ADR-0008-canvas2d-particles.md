# ADR-0008：粒子用 Canvas 2D 预烘焙 sprite

- 状态：已接受
- 日期：2026-11

## 背景

需要统一的消除/奖励/落地粒子，但同时满足：
主包 ≤ 3MB、低端安卓可玩、不推翻现有 Canvas 2D 架构。

## 选项

1. 换 WebGL 主渲染 —— 推翻 ADR-0005 与整套 2D 绘制代码；
2. 额外开 WebGL 离屏画布再 `drawImage` 合成 —— 每帧一次全屏拷贝，部分安卓更慢；
3. Canvas 2D + 预烘焙 sprite + 结构化数组 + blend 分批。

## 决策

选 **3**：

- 启动时把 7 种形状烘焙进一张 768×256 离屏图集；
- 粒子数据用 `Float32Array` SoA 布局，定长容量，运行期无对象分配；
- 按 `blend` 分两批绘制，避免逐粒子切换合成模式；
- 无旋转走 9 参数 `drawImage` 快路径；
- 超出预算丢弃最旧粒子。

## 后果

正面：包体 0 字节、风格统一、无全屏拷贝、300+ 粒子仍可 60fps。

负面：形状限制在 7 种；复杂效果（软体、流体）做不了。

## 约束

- 形状/颜色只能来自 `design-system`，游戏不得自造；
- 禁止每帧 `shadowBlur` / 重建渐变 / 全屏 shader；
- 后续若 WebGL 数据证明明显更优，用 ADR-0010 替换。
