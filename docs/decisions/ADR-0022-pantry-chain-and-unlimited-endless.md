# ADR-0022：王都仓库与「农场 → 加工屋 → 餐厅」产业链

- 日期：2026-11-27
- 状态：已接受；**部分被 [ADR-0023](./ADR-0023-warehouse-and-restaurant-three-lines.md) 取代**（餐厅改为厨房/点菜/营业三线、货物扩到 61 种、仓库加多选卖出与采购补齐、新增每日委托）。本 ADR 中「餐厅 3 窗口上菜」与「食材只有 8 种」的描述已过时。

## 背景

农场、加工屋、花园、水族馆各自闭环：农场作物只能自己卖或交订单，加工屋用王都币「进货」凭空生成莓果，餐厅一直停留在设计稿。结果是：

1. 场馆之间只有「都在大厅」这一层关系，没有可玩的联动；
2. 玩家在农场种的小麦对加工屋没有任何意义；
3. 经济里出现两种来源（买种子花币、进货又凭空生成原料），原料价值说不清。

同时，三消「无时间限制」用 30 步封顶，玩家想连续玩下去时会被硬性打断。

## 选项

1. **每个场馆各自维护原料**，加工屋/餐厅通过「送货」动作跨存档搬运 —— 需要玩家来回切馆，操作繁琐，且容易出现重复计数。
2. **共用一份王都仓库**（`profile.pantry`），所有场馆读写同一份食材 —— 跨馆天然一致，但需要把农场库存迁出来。
3. **维持现状**，只在文档里描述联动 —— 联动无法验证。

## 决策

采用选项 2：

- `Profile` 升到 v6，新增 `pantry: Record<string, number>`；只保留 `shared/content/ingredients.ts` 里的已知食材，0–999 上限；
- **农场 v2** 不再自带库存：收获、订单、一键卖出全部走 `profile.pantry`；v1 的 `inventory` 由 `legacyInventory()` 在进场时一次性搬进仓库；
- **加工屋 v2** 新增「原料间」页签：
  - 磨面粉：小麦 ×2 → 面粉 ×1（免费）
  - 烤面包：面粉 ×2 → 面包 ×1（2 王都币）
  产物同样进仓库；
- **新增 `restaurant` 分包**：3 个窗口、6 道菜，上菜时从仓库扣原料，给王都币 + 繁荣度；无倒计时、无失败；
- 货币只有王都币：烤面包的 2 币、种子、鱼食都走 `coins`，不引入第二种货币。

同批一起确定的两条规则：

- 三消「无时间限制」改为**真无限**：不计时、不限步数，HUD 正计时显示已用时间，随时退出结算；分数可能很大，UI 用 `shared/format.ts` 压缩成 `1.2万 / 3.6亿`；奖励按分数封顶 60 币/局，避免长局印钱；
- 大厅底栏**只放全局功能**（排行榜 / 每日 / 收集册 / 小铺），场馆入口只存在于街区建筑里；排行榜**只展示，不发王都币**。

## 后果

- 正面：
  - 一条可验证的产业链：种小麦 → 磨面粉 → 烤面包 → 上菜；
  - 农场作物有了「留下来加工」的理由，不再只有卖出；
  - 仓库集中在一处，跨馆不重复计数，存档更简单；
  - 排行榜不发币，避免刷榜动机与数值膨胀。
- 负面 / 代价：
  - 农场存档结构变化（v1 → v2），需要迁移逻辑与测试；
  - `profile.pantry` 成为热点数据，所有场馆写它都要 `profile.save()`；
  - 餐厅菜品价格必须与作物售价对齐，后续调价要同时看 `crops.ts` 与 `dishes.ts`（**现已合并到 `shared/content/ingredients.ts` + `menu.ts`，见 ADR-0023**）。
- 后续：
  - 餐厅可接套餐订单与菜谱图鉴；
  - ~~仓库可以在大厅出一个「仓库」页~~ → **已由 ADR-0023 实现**：西街库房设施 + 5 分页多选卖出面板。
