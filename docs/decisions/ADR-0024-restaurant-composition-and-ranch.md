# ADR-0024：餐厅组合台与牧场

- 日期：2026-11-27
- 状态：部分被 ADR-0025 取代（组合台/营业时长/火候部分；牧场与三消联动仍有效）
- 相关：ADR-0023（仓库与餐厅三线）、ADR-0025（3×3 灶眼图案与无时限营业）

## 背景

餐厅原来的「做一份 / 做三份」是一键产出，玩家不需要思考组合、空间或时间。牧场加入后，肉蛋奶需要一条与农场/加工屋不同、又能回到餐厅的产业链；三消也需要新的方块皮肤与跨场馆目标。

## 选项

1. 保持一键做菜，牧场只作为卖货来源；
2. 组合台 + 网格拖拽 + 组合计时，营业改为现做现卖；
3. 做完整的烹饪模拟（火候/锅具/多步骤），但超出休闲定位与工期。

## 决策

采用选项 2：

- 餐厅组合台 5×3 网格，两样拖到一起按配方输出，带 1.2–2.8 秒组合冷却；
- 只有成菜/茶饮能进成品柜或端给客人，半成品留在网格继续组合；
- 营业页客户排在上方，中间组合台，下方无限基础材料；成品可进 6 格配料区或直接拖给客人；
- 新增牧场分包：鸡/牛/猪/羊四栏，饲料（加工屋做）换肉蛋奶，牧产进王都仓库；
- 三消新增「牧场鲜货方块」皮肤，首次牧场收获解锁；
- 所有新货物走 `shared/content/ingredients.ts`，不新建第二套库存或价格。

## 后果

- 餐厅玩法从「点按钮」变为「拖拽 + 等待 + 空间管理」，营业不再是无脑端盘子；
- 产业链变为农场 → 加工屋（半成品/饲料）→ 牧场 → 餐厅；
- 餐厅存档升到 v3，需保存组合台与已发现配方；
- 牧场只有 4 栏、每栏 4 只，内容量可控；后续可加动物品种或畜栏升级，但不能引入付费加速。
