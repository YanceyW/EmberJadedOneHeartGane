# ADR-0003：云开发 + 本地优先

- 状态：已接受
- 日期：2026-02

## 背景

个人主体、无服务器、需要存档/排行榜/远程配置。
但不能因为云故障导致游戏不可玩。

## 决策

- 使用微信云开发；
- 所有操作先写本地；
- 云异步同步；
- 失败进离线队列；
- 冲突按游戏 merge；
- openid 只从云函数上下文取；
- 不做强制登录。

## 后果

正面：

- 免服务器；
- 离线可玩；
- 成本低；
- 隐私最小化。

负面：

- 需要处理冲突；
- 云函数冷启动；
- 需要备案（联机/云能力）；
- 免费额度有限。

## 约束

- 客户端无 Secret；
- 输入校验/限流；
- 删除账号必须可用；
- 云失败不阻塞。
