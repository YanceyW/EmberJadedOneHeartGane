# ADR-0012：三消固定 3 分钟 + 跨操作节奏加成

- 状态：已接受（每日挑战部分由 ADR-0020 取代）
- 日期：2026-11

## 背景

王都三消原设计是「步数 + 目标分数」双约束：24 步左右打完一关，节奏偏慢，且换局时间长。
在保持休闲、单手竖屏、无体力的前提下，希望：

- 一局时长稳定、可预期；
- 分数有持续上涨的空间，而不是「步数用尽就结束」；
- 操作手感更直接（滑动交换），并奖励连续快速操作。

## 选项

| 方案 | 说明 | 结论 |
|---|---|---|
| 保留步数 | 改动最小，但节奏与「时间感」都不够 | 否 |
| 无时间限制 | 最休闲，但和「改成倒计时」的目标冲突，也缺少短局节奏 | 否 |
| **固定 3 分钟 + 目标分数逐关上涨** | 时间固定、目标上涨，短局可控 | **采用** |

## 决策

1. **计时**：所有关卡与每日挑战固定 180 秒；达到目标立即胜利，时间归零未达目标失败。
2. **计时口径**：消除动画期间继续计时；只有切后台（`App` 的 update 循环停止）时暂停。
3. **目标**：1500 → 4200 逐关上涨；每日 4000。星级仍为 1x / 1.25x / 1.5x。
4. **节奏加成**：距上次成功交换 ≤ 2.0 秒，节奏档位 +1（1–6 档）；倍率 `1 + 0.15 × (档位 - 1)`，最高 ×1.75；音高每档 +2 半音，与连锁叠加封顶 +12。
5. **输入**：棋盘只允许滑动交换；点击不选中、不交换。HUD/结算按钮仍可点击。
6. **表现**：节奏档位同步驱动音高、粒子规模、飘字颜色与 HUD 节奏条。

## 后果

正面：

- 一局 3 分钟，适合休闲短局与「再来一局」；
- 节奏加成让高手有明确的分数上限空间，同时不影响普通玩家达标；
- 滑动比「点两下」更直接，误触更少。

代价与约束：

- 旧目标按 20–24 步配平，必须整体上调，否则三星失去意义；
- 时间压力会让部分玩家紧张，需要清晰的警告与音效；
- 冒烟测试必须从「点击两格」改成「touchstart → touchmove → touchend」；
- 节奏属于单局状态，不入存档，不改变 `schemaVersion`。

## 调参入口

- `src/games/match3/data/levels.ts`：每关 `seconds` / `target`；
- `src/games/match3/data/daily.ts`：每日时长与目标；
- `src/games/match3/systems/tempo.ts`：窗口、档位、倍率步长、音高上限。
