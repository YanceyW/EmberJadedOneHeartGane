# ADR-0001：单运行时 + 多玩法

- 状态：已接受
- 日期：2026-02

## 背景

要做合集，需要多款游戏共享大厅、UI、存档、云、广告、音频。
可选：

1. 每款游戏独立工程/引擎；
2. 一个重型引擎装多款游戏；
3. 一个轻量运行时 + 多玩法。

## 决策

采用 **TypeScript + Canvas 2D 自研轻量运行时**：

- 单运行时；
- 每款游戏实现 `GameDefinition`；
- 游戏独立分包；
- 共享 core/shared。

## 后果

正面：

- 包体可控；
- 共享能力强；
- 风格统一；
- 新游戏接入快。

负面：

- 需要自己实现场景/渲染/输入/资源；
- 高级 3D/物理不支持；
- 需要严格工程规范。

## 备选

- Unity：运行时大、主包放不下、多游戏共享难；
- Cocos：同样偏重；
- Phaser/Pixi：自带运行时，和自研重复。

## 约束

- 不混引擎；
- 不引入 bundler；
- 单款游戏不得绕过 core 直接调 wx。
