# ADR-0007：游戏资产随分包

- 状态：已接受
- 日期：2026-02

## 背景

主包只有 4MB 预算（本项目目标 3MB）。如果所有游戏的图片/音频都放在 `dist/assets`，主包会被迅速占满，分包就失去意义。

## 决策

- 共享 UI/图标/SFX：`assets/shared` → `dist/assets/shared`（主包）；
- 游戏独有资产：`assets/games/<id>` → `dist/games/<id>/assets`（分包根内）；
- 构建脚本按 `dist/games/<id>` 是否存在决定是否复制；
- 检查包体时，游戏资产计入对应分包，不计入主包。

## 后果

正面：

- 主包保持轻量；
- 游戏资产随分包加载/释放；
- 包体报告更真实。

负面：

- 资产路径在运行时是 `games/<id>/assets/...`；
- 共享资产不能复制到游戏目录；
- 游戏退出时需要释放分包纹理（代码常驻）。

## 约束

- 禁止把游戏大图放到 `dist/assets/games`（该目录不再作为运行时路径）；
- 新增游戏必须把独有资产放 `assets/games/<id>`。
