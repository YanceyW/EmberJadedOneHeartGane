# ADR-0019：三消达标后继续冲星 + 提前结算

- 状态：已接受（每日挑战已由 ADR-0020 移除）
- 日期：2026-11

## 背景

三消沿用「固定 3 分钟 + 目标分数」：达到目标立即胜利结算。

但星级是 1x / 1.25x / 1.5x 目标分，达标即结束意味着 **2 星和 3 星永远拿不到**；玩家也反馈「目标分一达成就被踢出局，没法继续打」。

## 选项

1. 达标即结束（旧行为）：简单，但三星不可达，星级系统失效。
2. 降低三星线到 1x：三星失去意义，且与「目标分」重复。
3. **达标后继续，计时结束或手动结算**：保留 3 分钟压力，又给冲星空间。
4. 达标后直接结束但按当前分补星：仍然无法主动冲星，玩家没有操作空间。

## 决策

采用选项 3：

- 达到目标分时：
  - 记 1 星、解锁下一关、写入最佳分并立即落盘；
  - 不结束回合，计时继续；
  - 顶部出现「提前结算」按钮；
  - 提示「目标达成！继续冲三星，或点提前结算」。
- 1.25x / 1.5x 达成时实时补星并落盘，避免中途退出丢星。
- 结束条件只剩两个：时间归零、点「提前结算」。
- 时间归零时若已达目标，按胜利结算而不是失败。
- 冲星途中点返回：按胜利结算，保留首通奖励与星级。
- 每日挑战没有星级，保持「达标即结束」。

## 后果

- 三星终于可达，星级成为可追求的目标；
- 玩家可以自己决定「稳一星走人」还是「贪三星」；
- 达标后仍需承担时间风险，3 分钟压力保留；
- 首通奖励在达标时先记 `firstClear`，结算时不会因星级已落盘而误判成非首通；
- 需要新增 `systems/progress.ts`（星级门槛/进度条比例）与 HUD 的结算按钮、星级刻度；
- 进度条改为 0 → 1.5x 目标，右侧显示「距过关 / 距 N 星多少分」，避免百分比与条长不一致；
- 读档 schema 不变（仍为 v3），只改变单局流程。

## 约束

- 不卖时间、步数、分数、道具；
- 「提前结算」不是付费点，只是操作；
- 每日挑战不引入星级，避免与闯关进度混淆；
- 方块主题只换外观，不改变消除规则与难度。
