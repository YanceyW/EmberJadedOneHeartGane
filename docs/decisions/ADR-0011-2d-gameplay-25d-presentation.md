# ADR-0011：2D 玩法 + 2.5D 表现

- 状态：已接受
- 日期：2026-11

## 背景

希望画面有体积感（不要扁平贴纸感），但玩法是 2D 网格。

## 三个候选

| 方案 | 视觉 | 复杂度 | 每帧成本 |
|---|---|---|---|
| 纯平面 2D | 低 | 无 | 最低 |
| 等距/透视 2.5D 棋盘 | 高 | 高（iso 坐标、深度排序、命中反变换） | 中高 |
| **2D 玩法 + 2.5D 表现** | 高 | 无 | 低 |

## 决策

选第三种：

- 玩法层保持**正视矩形网格**，命中就是矩形格，逻辑与测试完全不变；
- 体积感靠表现层：
  1. 方块挤出侧边 + 顶面高光（预烘焙 sprite）；
  2. 落地软阴影（随离地高度缩放/淡出）；
  3. 下落 0.94→1.0 近大远小；
  4. 面板/按钮厚边，按下整体下移；
  5. 大厅三层视差（0.2 / 0.5 / 1.0）；
  6. 统一左上暖光与投影方向。

## 为什么不选等距棋盘

1. 竖屏 6×8 格本就小，斜 45° 后有效像素更少，可读性下降；
2. 下落动画在 iso 下要么走斜线（反直觉）要么竖直（穿帮）；
3. 命中反变换 + 遮挡排序引入额外 bug 面，玩法逻辑并不需要；
4. 成熟 2.5D 三消（Candy Crush / Royal Match）棋盘也是正视矩形。

## 约束

- 命中区域永远是矩形逻辑格；视觉偏移/缩放 ≤ 6%；
- 每屏最多 2 个深度线索；
- 禁止每帧 `shadowBlur`，一律预烘焙；
- 不做透视/倾斜的玩法网格。
