# ADR-0018：农场作为食材游戏，不与花园重叠

- 状态：已接受
- 日期：2026-11

## 背景

用户希望增加农场种地，并询问是否会和「王都花园」重叠；同时希望所有游戏与王都币形成循环，且能通过后续审核。

如果农场也做「种花/收集」，会与花园的遗传/图鉴直接竞争；如果农场只做食材，则能和加工屋、餐厅、水族馆鱼食形成分工。

## 决策

- **农场 = 食材生产**：小麦、胡萝卜、草莓、南瓜；
- **花园 = 花卉遗传/收集/布置**：不产出食材；
- **加工屋 = 加工**：把农场食材变成甜品；
- **餐厅（规划）= 成菜**：农场食材 + 合成甜品做套餐；
- **水族馆 = 鱼**：鱼食可由农场兑换，鱼不抽卡；
- 农场种子、开地、订单全部用王都币；
- 农场离线按时间生长，不死亡；
- 首版只做本地存档 `save:farm`，不接云同步。

## 后果

- 农场和花园有明确边界，不会做成两个「种花」游戏；
- 王都币有新的消耗（种子/开地）和产出（订单/卖作物）；
- 加工屋/餐厅/水族馆有共同食材来源；
- 新增一个 playable 分包，包体约 0.03MB；
- 后续需要把农场食材接入加工屋订单。

## 约束

- 不做偷菜、陌生人社交、排行榜攀比；
- 不卖种子/加速/真实货币；
- 不做抽卡、盲盒、内购、强制广告；
- 离线收益有上限，不惩罚玩家；
- 农场 UI/图标必须复用 `visual-style.md`。
