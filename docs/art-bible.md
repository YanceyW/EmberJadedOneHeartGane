# 美术圣经（Art Bible）

> 统一视觉的最终依据。新资产先对照本文，再进资产库。
> 具体画法、代码 API、图标/棋盘/天气/节日规则见 [visual-style.md](./visual-style.md)。

## 1. 世界观

「休闲王都」是一座平铺在柔和丘陵上的小城，远处是云海、屋顶和山丘：

- 房子是奶油色/薄荷色/蜜桃色，屋顶圆润，窗户暖黄；
- 街道有花瓣、纸灯、喷泉、小猫，地面是平铺的草地与石板路；
- 没有战争、恐怖、阴暗、写实脏污；
- 每个场馆是一栋小建筑，门口有招牌和排队小人；
- 白天偏暖、傍晚偏金、夜晚偏蓝紫 + 暖灯；
- 世界向左右延伸，可单指平移、双指缩放，为后续街区留位置。

## 2. 视觉支柱

1. **圆润**：没有尖角，所有转角都有半径；
2. **奶油**：低饱和暖底，不用纯白；
3. **纸雕**：厚暖描边、平涂三阶色、叠纸阴影、轻纸纹；
4. **统一光照**：左上暖光，3 阶明暗；
5. **有限颜色**：每屏主色 ≤ 5 个 + accent；
6. **可读**：缩放到 0.85–1.2 时轮廓仍清楚，不靠细节堆砌。

## 3. 角色

- Q 版 2 头身；吉祥物 2 头身；
- 大眼睛、小嘴巴、圆手圆脚、腮红；
- 表情夸张但友善，眨眼/呼吸/轻微摇摆即可；
- 服装用大色块 + 少量纹样，换装只换配色与配饰；
- 不做写实人体、不做性感化、不做恐怖；
- 角色由代码矢量绘制并缓存，不逐帧重算路径。

## 4. 场景

### 大厅（王都街区）

- 平铺地面 + 宽世界：中央喷泉/广场，四馆围绕，东街尽头是农场；左右可平移、双指缩放；
- 前景花草/小猫/路灯/花车，中景建筑，远景屋顶/山丘/云海；
- 建筑招牌用代码渲染文字，图片不带文字；
- 昼夜：清晨暖粉、白天奶油绿、黄昏蜜桃金、夜晚蓝紫 + 暖灯 + 星光；
- 未开放场馆用木牌「装修中」+ 微暗室内，不再搭满脚手架；可游玩场馆有「可游玩」徽章与暖窗；
- 静态天空/地面/建筑按昼夜阶段烘焙，动态只叠加招牌摆动、烟、窗光、粒子和角色。

### 王都农场

- 食材主题：小麦、胡萝卜、草莓、南瓜；
- 谷仓红屋顶 + 奶油墙 + 木门 + 筒仓 + 干草；
- 土地是棕色纸片，田垄用暖棕线；
- 作物图标必须一眼区分，不能只靠颜色；
- 不做偷菜/社交/真实货币。

### 王都三消

- 甜品/宝石主题：马卡龙、莓果、星星、蜂蜜罐；
- 棋盘背景是奶油纸 + 淡格纹；
- 消除特效：花瓣/星光/糖霜，不用爆炸/火焰。

### 王都花园

- 花圃、温室、木栅栏、蝴蝶；
- 花色来自遗传系统，素材用可染色花瓣；
- 背景是柔和草地 + 远山 + 云。

### 王都加工屋

- 厨房/店铺：木架、糖罐、烤箱、格子桌布；
- 甜品链从原料到蛋糕，颜色暖；
- 合并特效：糖霜/闪光/小星星。

### 王都水族馆

- 水蓝/浅紫，玻璃缸、水草、珊瑚、气泡；
- 鱼纹由算法生成，鱼身用可染色模板；
- 光照从水面下投，柔和焦散。

## 5. 材质/光照

- 纸张颗粒：低透明度噪声，烘焙进天空/地面/建筑；
- 纸雕边缘：2–3px 暖色厚描边 + 轻微抖动，不追求机械直线；
- 平涂：每块颜色 2–3 阶（亮/中/暗），不用连续渐变堆细节；
- 叠纸阴影：暖棕偏移阴影，透明度 0.15–0.25，营造层叠纸片感；
- 高光：柔和、低对比，不用镜面白点；
- 阴影：暖灰/深棕，透明度 0.15–0.25；
- 不用照片纹理、金属反射、HDR。

## 6. 构图

- 竖屏 9:16；主体在中上部，底部留操作区；
- 视觉重心偏上 1/3；
- 前景/中景/远景三层；
- 重要按钮不被手指遮挡；
- 文字用代码渲染，图片不嵌文字。

## 7. AI 生成规范

### 7.1 通用正向提示词

```
cute cozy mobile game art, cream and mint palette, paper-cut layered illustration,
thick warm outline, flat 3-tone shading, soft paper grain, rounded chibi shapes,
top-left warm light, storybook composition, no text, no logo, no watermark,
high quality, centered subject
```

### 7.2 通用负向提示词

```
realistic, photorealistic, dark, horror, gore, neon cyberpunk, sharp spikes,
pure black, pure white, text, letters, watermark, logo, extra limbs,
deformed hands, cluttered background, high contrast, metallic
```

### 7.3 每款追加

- 三消：`macaron, berry, star, honey jar, candy, soft grid background`
- 花园：`flower garden, greenhouse, butterfly, wooden fence, pastel petals`
- 合成：`cozy bakery, sugar jar, oven, checkered tablecloth, dessert`
- 水族馆：`aquarium, water plant, coral, bubble, soft caustics, koi fish`

### 7.4 生成参数

- SDXL Lightning 4-step，1024×1024 或 832×1216；
- CFG 1.5–2.5；固定 seed 便于复现；
- 一次 4–8 张候选；
- 生成记录：prompt/negative/seed/model/date；
- 只选 1 张进入修图。

## 8. 资产规格

| 类型 | 规格 |
|---|---|
| 图标 | 96×96 / 144×144，透明 PNG/WebP；当前阶段由代码绘制，纯 2D 平面，不做挤出/透视 |
| 角色 | 512–1024，切件 |
| 场景 | 750×1334 或分层 |
| UI 九宫格 | 可拉伸，边缘 24–48 |
| 图集 | ≤ 2048×2048 |
| 音频 SFX | **不占包体**：运行时用 WebAudio 合成（见 `docs/motion.md`） |
| BGM | 30–45s 循环，96kbps 单声道 mp3 |

## 9. 禁止

- 纯黑/纯白大面积；
- 写实人脸/明星/品牌；
- 恐怖/血腥/性感化；
- 图片内文字（用代码渲染）；
- 未授权字体/素材；
- 每款游戏自创 UI 风格。
