# 性能与包体预算

## 1. 包体

| 项目 | 目标 | 门禁 |
|---|---|---|
| 主包 | 3.0MB | 3.2MB |
| 单款 | 2.0MB | 2.5MB |
| 总包 | 30MB | 平台 |

### 省包体

1. 程序化 UI/背景/图案 + 缓存；
2. 图集复用；
3. WebP/压缩；
4. 音频单声道/低码率；
5. 数据用 JSON + seed；
6. 系统字体；
7. 构建检查。

## 2. 运行时

| 项目 | 目标 | 降级 |
|---|---|---|
| FPS | 60 中端 | 30 低端 |
| 逻辑/帧 | ≤4ms | 降 AI/粒子 |
| 渲染/帧 | ≤8ms | 降分辨率/缓存 |
| 冷启动 | ≤3s | 预加载 |
| 进游戏 | ≤2s | 预下载 |
| 内存 | ≤180MB | 释放纹理 |

## 3. 程序化

- 生成一次，缓存；
- 单屏 <50ms；
- 缓存 ≤32MB/游戏；
- LRU + 引用计数；
- 退出释放；
- 超预算改预烘焙。

## 4. 渲染

- 静态层缓存；
- 合批/减少状态切换；
- 粒子上限；
- 对象池；
- 避免每帧创建对象；
- 避免每帧 `measureText`。

## 5. 内存

- 纹理释放；
- 音频池；
- 事件解绑；
- 定时器清理；
- 分包常驻但资源可释放；
- 低端机降 DPR。

## 6. Profiling

- 微信开发者工具 Performance；
- 真机 `wx.getPerformance()`；
- 自定义计时器（update/render/load）；
- 记录 P50/P95；
- 每次发版对比基线。

## 7. 降级策略

```
高 → 中 → 低
- 粒子 400 → 200 → 100
- DPR 3 → 2 → 1.5
- 阴影/模糊 开 → 关
- 背景动画 开 → 静态
- 目标 60 → 30fps
```

降级必须自动、可配置、不改变玩法。
