# 性能与包体预算

## 1. 包体

| 项目 | 目标 | 门禁 |
|---|---|---|
| 主包 | 3.0MB | 3.2MB |
| 单款 | 2.0MB | 2.5MB |
| 总包 | 30MB | 平台 |

### 省包体

1. 程序化 UI/背景/图案 + 缓存；
2. 图集复用；
3. WebP/压缩；
4. 音频单声道/低码率；
5. 数据用 JSON + seed；
6. 系统字体；
7. 构建检查。

## 2. 运行时

| 项目 | 目标 | 降级 |
|---|---|---|
| FPS | 60 中端 | 30 低端 |
| 逻辑/帧 | ≤4ms | 降 AI/粒子 |
| 渲染/帧 | ≤8ms | 降分辨率/缓存 |
| 冷启动 | ≤3s | 预加载 |
| 进游戏 | ≤2s | 预下载 |
| 内存 | ≤180MB | 释放纹理 |

## 3. 程序化

- 生成一次，缓存；
- 单屏 <50ms；
- 缓存 ≤32MB/游戏；
- LRU + 引用计数；
- 退出释放；
- 超预算改预烘焙。

### 3.1 大厅烘焙

- `TownArt` 按昼夜阶段烘焙：
  - 天空：视口宽 ×（地平线 + 300）；
  - 地面：世界宽 1800 ×（屏幕高 - 地平线 + 280）；
  - 建筑：每栋独立画布，含 34px 阴影边距；
- 每个图层 LRU 保留 2 个阶段；切阶段只换图，不重建路径；
- 平移/缩放只改变 `drawImage` 的目标矩形，不触发重新烘焙；
- 切换画质/纸纹/节日风格时使缓存失效并重建；
- 高/中/低档只改变装饰数量（草丛、花、地面色块）与是否叠纸纹，不改变布局。

### 3.2 天气与主题

- 天气覆盖每帧最多 92 个公式化雨/雪/花瓣，画在场景之上、UI 之下；
- 节日风格只改调色与少量装饰，切换时重烘焙一次；
- 天气/节日都不新增图片资产；
- 低画质/减少动效关闭天气粒子，保留色调。

## 4. 渲染

- 静态层缓存；
- 合批/减少状态切换；
- 粒子上限；
- 对象池；
- 避免每帧创建对象；
- 避免每帧 `measureText`。

## 5. 内存

- 纹理释放；
- 音频池；
- 事件解绑；
- 定时器清理；
- 分包常驻但资源可释放；
- 低端机降 DPR。

## 6. Profiling

- 微信开发者工具 Performance；
- 真机 `wx.getPerformance()`；
- 自定义计时器（update/render/load）；
- 记录 P50/P95；
- 每次发版对比基线。

## 7. 反馈与表现层预算

| 项目 | 目标 | 低端降级 |
|---|---|---|
| 粒子 | 240（mid） | 120（low） |
| 大厅环境粒子 | 96（mid） | 48（low） |
| 单屏粒子峰值 | ≤ 400 | ≤ 120 |
| 同时发声 | 6 | 3 |
| Tween 活跃数 | ≤ 40 | ≤ 40 |
| 动画时长上限 | 单次操作 320ms | 同 |

- 粒子走预烘焙图集 + SoA 池，**包体 0 字节**，`drawImage` 合成由 GPU 完成；
- 禁止每帧 `shadowBlur` / 重建渐变 / 全屏 shader；
- 设备档位与降级见 [motion.md](./motion.md) §5.3。

### 7.1 玩家可调项

设置 →「画面」暴露以下开关，持久化到 `Profile.settings`：

| 设置 | 作用 |
|---|---|
| 画质 | 自动 / 高 / 中 / 低 |
| 性能模式 | 强制低画质 + 关闭环境/场景动效/纸纹 |
| 环境效果 | 花瓣、落叶、萤火虫、喷泉水花、烟 |
| 场景动效 | 招牌摆动、角色呼吸、居民走动、猫尾 |
| 纹理细节 | 纸纹/颗粒叠加 |
| 屏幕震动 | 三消等场景的震动 |
| 减少动效 | 关闭非必要动效与粒子 |

所有开关立即生效；关闭后必须保留可玩性和可读性。

## 8. 降级策略

```
高 → 中 → 低
- 粒子 400 → 240 → 120
- 大厅环境粒子 160 → 96 → 48
- DPR 3 → 2 → 1.5
- 阴影/模糊 开 → 关
- 背景动画 开 → 静态
- 纸纹 开 → 关
- 目标 60 → 30fps
```

降级必须自动、可配置、不改变玩法。
