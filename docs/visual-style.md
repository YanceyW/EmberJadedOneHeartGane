# 视觉风格总纲（AI 必读）

> 目标：后续新增游戏、图标、弹窗、天气、节日外观时，AI 不需要重新猜风格。
> 本文是「怎么画」的单一入口；颜色 token 以 `docs/design-system.md` 为准，世界观以 `docs/art-bible.md` 为准。

## 1. 一句话

**奶油纸雕童话 + Q 版 2 头身 + 平涂三阶色 + 厚暖描边 + 轻纸纹。**

关键词：奶油、圆润、纸片层叠、手作温度、清楚轮廓、低饱和暖底、有限颜色、可读性优先。

不做：写实、厚涂、赛博、暗黑、恐怖、照片纹理、金属反射、HDR、纯黑纯白、每帧矢量重绘。

## 2. 两个必须遵守的 ADR

- [ADR-0015 奶油纸雕童话视觉系统](./decisions/ADR-0015-paper-storybook-visual-system.md)：风格本体、程序化笔刷、烘培策略。
- [ADR-0016 平铺可平移王都世界](./decisions/ADR-0016-pannable-town-world.md)：大厅世界、相机、地图扩展。

视觉改动若违反这两个 ADR，先改 ADR，再改代码。

## 3. 颜色与材质

### 3.1 基础 token

- 底色：`cream` / `paper`
- 主色：`jade` / `mint` / `teal`
- 暖色：`peach` / `coral` / `gold` / `honey`
- 辅助：`lilac` / `sky` / `leaf` / `petal` / `berry`
- 描边：`ink`（暖深棕），次文字 `inkSoft`
- 阴影：暖棕透明，alpha 0.15–0.25

大厅专用色只能从 `TOWN_COLORS`、`TOWN_PHASES`、`PAPER_UI` 取，不在场景里写死色值。

### 3.2 纸雕三层

每个物体最多三层：

1. **底色**：平涂，不用连续渐变；
2. **暗部/亮部**：同色系深一档或浅一档，形成 2–3 阶；
3. **墨线 + 偏移阴影**：2–3px 暖色描边，阴影向左下偏移 3–6px。

高光只用一块低透明度纸片，不用镜面白点。

### 3.3 纸纹

- 只烘焙进静态层（天空、地面、建筑）；
- 低档/性能模式可关闭；
- 不用每帧随机噪声，固定 seed；
- 纸纹 alpha 约 0.04–0.08，不能影响文字可读性。

## 4. 形状与笔触

- 所有转角有半径：8 / 12 / 16 / 24；
- 描边圆头、圆角连接；
- 允许轻微手抖，不允许锯齿/自交；
- 圆角矩形路径必须顺时针闭合，使用 `roundRectPoints`；
- 同一形状的抖动 seed 固定，否则会「呼吸」。

### 代码入口

| 模块 | 用途 |
|---|---|
| `src/shared/design-system/paint.ts` | 抖动路径、墨线、圆角、软阴影、纸纹、胶带 |
| `src/shared/design-system/paper-ui.ts` | 纸面板、贴纸按钮、开关、分段标签、设置行、木牌 |
| `src/shared/design-system/royals.ts` | Q 版国王/王后 |
| `src/shared/design-system/sprite-atlas.ts` | 方块、阴影、粒子 |
| `src/lobby/town/town-art.ts` | 大厅静态层烘焙 |
| `src/lobby/town/town-buildings.ts` | 场馆建筑（含农场）与动态覆盖 |
| `src/lobby/town/town-view.ts` | 大厅相机渲染、角色、前景、装饰 |
| `src/lobby/weather.ts` | 天气覆盖层（雨/雪/花瓣） |
| `src/lobby/themes.ts` | 天气、节日风格、价格与调色 |

新增游戏不得再复制一套 paint/paper-ui；只允许组合这些 API。

## 5. 角色

- Q 版 2 头身，头大身小；
- 大眼睛、小嘴巴、圆手圆脚、腮红；
- 眨眼、呼吸、轻微摇摆即可，不做复杂骨骼；
- 服装为大色块 + 少量纹样（领口滚边或围裙一处即可）；
- 国王/王后共用 `drawRoyalPair`，换装只换配色与配饰；
- 居民无名、无标签、不可点击、不可换装；
- 居民身份是王都自己的街坊与店员（孩童/少年/姑娘/店家/花匠/水族馆店员/农人/阿婆），
  差异靠剪影：头饰形状、身高、体宽、是否挎篮/拄杖；
- 帽子必须按头部半径贴着画（斗笠锥顶压在头顶，帽檐不宽于肩），禁止悬空宽檐；
- 中国味放在配色（朱砂/黛青/竹青/杏黄/藕荷）与一处小纹样，不穿历史戏服、不做角色扮演；
- 不写实、不性感化、不做恋爱叙事。

## 6. 建筑

- 一馆一栋，轮廓识别优先于细节；
- 屋顶圆润，墙面奶油/薄荷/蜜桃；
- 招牌由代码渲染文字，图片不带字；
- 窗户暖黄，夜晚有柔和窗光；
- 未开放场馆：木牌「装修中」+ 微暗室内，不铺满脚手架；
- 可游玩场馆：「可游玩」丝带 + 呼吸描边 + 暖窗；
- 建筑静态 body 烘焙，动态只叠加招牌/烟/窗光/丝带。

## 7. 图标

### 7.1 场馆图标

- 纯 2D 平面，不做 2.5D 挤出；
- 统一圆头描边 2.5px；
- 每种游戏只用一个主色 + 一个辅色；
- 图标必须能缩到 26px 仍可辨认；
- 大厅、商店、结算、排行榜复用同一函数，不另画一套。

当前入口：`src/lobby/game-icons.ts`。

### 7.2 三消入口图标

- `candy`：三颗圆糖，中间笑脸；
- `swap`：两块糖斜向交换 + 弧形箭头；
- `honey`：蜂蜜罐 + 星星糖；
- 全部使用纸雕平涂 + 厚描边 + 纸片高光；
- 不使用 emoji。

### 7.3 三消方块（场馆联动）

- 方块是「王都里端上来的东西」：甜品屋的甜点、农场的作物、食集的面包；
- 8 个预烘焙精灵：莓果 / 蜂蜜罐 / 薄荷糖 / 马卡龙 / 花瓣 / 胡萝卜 / 面包 / 麦穗；
- **皮肤在王都小铺「方块」页购买**，当前装备决定 5 个方块；只换外观，不改变消除规则与难度；
- 区分三重奏：**独立轮廓 + 底纹 + 色相**。方罐、三角胡萝卜、圆面包、麦穗、花形必须一眼分开；
- 灰度检查：去掉颜色后仍能靠轮廓/底纹配对，才算合格；
- 新主题优先复用已有精灵，确需新精灵时保持 `ATLAS_W = 128 × 精灵数`。

### 7.4 农场作物

- 小麦/胡萝卜/草莓/南瓜必须靠轮廓区分，不能只靠颜色；
- 成熟与幼苗只改变大小/完整度，不换一套画法；
- 种子卡、订单、土地里复用同一个 `drawCrop`；
- 作物颜色从 token 取，不写死新色值。

### 7.5 农场田地

- **QQ 农场式 3×3 方块田**，不是大卡片或列表；
- 每块地：木框 + 土面（横向田垄 + 石子）+ 顶部纸片高光；
- 成熟：作物轻晃、金色光环、「可收获」纸标签、满格金条；
- 生长：按剩余时间显示进度条与秒数，作物随时长变大；
- 锁定：草皮底 + 锁；下一块标价，后面的写「待开垦」，不制造“三块都能买”的误解；
- 种子用「种子包」卡片（作物图 + 名称 + 价格 + 持有），选中有金色描边；
- 田地前后加风车/谷仓/树/篱笆小景，保持纸雕俯视，不做真 3D。

### 7.6 花园 / 加工屋 / 水族馆

- 花园：木框苗床 + 纸片花茎/花瓣；浇水用 `bubble` 粒子；成熟用金色「可收获」纸签；底部可加栅栏与花盆小景。
- 加工屋：5×5 纸片加工台；莓果/果酱罐/蛋糕/宴席四套轮廓；选中用金色描边；订单卡与三键按钮复用 `paper-ui`。
- 水族馆：水色圆角鱼缸格 + 墨线鱼（`drawFish`）+ 三条成熟刻度；成熟鱼头顶王都币小徽章；底部可加沙地/水草/海星。
- 高屏底部不要留大片空白：补一条同色系场景带（花圃/货架/沙地），低屏自动省略。

## 8. 三消棋盘

- 背景：奶油纸 + 远处纸云/小山 + 纸旗；
- HUD：纸面板、缝线、贴纸按钮；
- 棋盘底板：纸面板 + 圆角格；
- 方块：平涂三阶色 + 3px 暖描边 + 底部内阴影 + 顶部纸片高光；
- 方块区分必须同时靠颜色 + 轮廓/符号 + 纹理，灰度也能配对；
- 当前装备的方块皮肤决定 5 个方块（甜品屋/农场/王都食集，王都小铺购买），详见 7.3；
- 进度条按三星门槛铺满（0 → 1.5x 目标），星标就是刻度，不用会与条长对不上的百分比；
- 消除粒子：花瓣/星屑/糖霜，不用爆炸/火焰；
- 结算面板与大厅用同一套 `paper-ui`。

## 9. UI 与弹窗

- 所有卡片/按钮/开关/标签来自 `paper-ui`；
- 面板：纸底 + 虚线缝线 + 2px 暖描边 + 轻阴影；
- 按钮：贴纸厚边，按下下沉 3–4px；
- 分段标签：胶囊底 + 选中纸片；
- 弹窗遮罩：`rgba(58,46,42,0.35–0.42)`；
- 字号只用 20/24/28/32/40（特殊小字 12–16 可作辅助）；
- 文字只用系统字体，不引字体包。

## 10. 天气与节日

天气是**免费**的，节日风格用王都币购买；两者都不影响数值。

- 天气：晴、雨、雪、花瓣风；
- 天气覆盖层画在场景之上、UI 之下；
- 天气分三层（远/中/近）：雨=雨丝 + 地面水花圈；雪=雪花 + 雾带 + 底部积雪；花瓣=阵风 + 旋转花瓣；
- 雨/雪/花瓣数量受画质预算控制，先铺一层按天气缓存的氛围渐变，减少动效时只留这层色调；
- 节日风格：纸雕（默认）、桃花春色、灯会之夜、秋收市集、暖冬灯火；
- 节日装饰用中国传统题材：桃花树/纸鸢/油纸伞、红灯笼/灯谜木牌/走马灯、稻穗/玉米辣椒/南瓜/酒坛、雪堆/红灯笼/腊梅/糖葫芦；
- 节日风格改变调色与装饰，不改变玩法；
- 风格与天气可自由组合；
- 低端机/减少动效时关闭天气粒子，只保留静态色调。

## 11. 新内容验收清单

新增一款游戏 / 一个图标 / 一个弹窗 / 一个节日包时逐项检查：

- [ ] 颜色来自 token，没有写死新色值；
- [ ] 有 2–3 阶明暗 + 暖色描边 + 偏移阴影；
- [ ] 缩到 26px / 0.85 缩放仍可读；
- [ ] 静态层已烘焙，未逐帧画复杂路径；
- [ ] 粒子来自统一图集，未新造形状；
- [ ] 按钮/面板来自 paper-ui；
- [ ] 低画质/减少动效有降级；
- [ ] 文档更新，必要时写 ADR；
- [ ] 截图与 `npm run verify` 通过。

## 12. AI 生成/绘图提示词

正向：

```
cute cozy paper-cut storybook game art, cream and mint palette, thick warm outline,
flat 3-tone shading, layered paper shadows, soft paper grain, rounded chibi 2-head
characters, top-left warm light, clean readable silhouette, no text, no logo,
no watermark, portrait composition, high quality
```

负向：

```
realistic, photorealistic, 3d render, glossy plastic, neon, cyberpunk, dark horror,
gore, metallic reflections, hdr, pure black, pure white, noisy texture, cluttered,
text, letters, logo, watermark, extra limbs, deformed hands
```

若生成的是图标：追加 `single centered icon, flat colors, thick outline, transparent background`。

## 13. 经济与玩法边界

新游戏/新装饰接入前先读 [game-design/economy-loop.md](./game-design/economy-loop.md)：

- 农场只做食材，花园只做花卉；
- 加工屋做加工，餐厅做成菜；
- 水族馆鱼食可由农场兑换；
- 所有王都币玩法都不卖数值、不内购、不抽卡；
- 新入口优先复用现有场馆/底栏，不无限增加首屏按钮。

## 14. 不要做的事

- 不要为单个游戏新建一套颜色/描边/字体；
- 不要把渐变、阴影、纸纹每帧重画；
- 不要在游戏内直接 `wx.*`；
- 不要用 emoji 当正式图标；
- 不要把 AI 原图/PSD/未压缩音频打进包；
- 不要做写实恋爱、UGC、聊天、抽卡、内购、强制广告。
