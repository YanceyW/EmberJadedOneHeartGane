# 王都水族馆

> 状态：可玩原型（`src/games/aquarium`，分包 `aquarium`）。
> 原型规则：6 个鱼位；**8 种鱼**（小金鱼 60 → 龙鱼 460 王都币）；喂食 4 币/次，3 次成熟；成熟鱼每 15 秒产 1 泡泡币，单条最多攒 20；点鱼收币，也可「收全部泡泡币」；访客订单要求成熟鱼数量，给王都币+繁荣度。存档 `save:aquarium`，离线按真实时间积累。排行榜 id `aquarium`。
>
> 本文第 3–9 节是长期设计（繁育/鱼纹/造景/双人），**当前原型只实现了「买鱼 → 喂食 → 收泡泡币 → 访客订单」**，未实现的部分在每节开头标了「未实现」。

## 1. 核心

买鱼 → 喂食 → 成熟 → 收泡泡币 / 访客订单 → （规划）繁育与造景。

> 与 [farm.md](./farm.md) 的关系：鱼食直接花王都币（4 币/次），不消耗作物；鱼只做饲养/收集，不抽卡、不买卖真实货币。

## 2. 循环

```
短：喂鱼/收币（30 秒）
中：访客订单/收集（1–7 天）
长：（规划）造景/赛季鱼
```

### 遗传

- 体型/鳍：显隐；
- 颜色：Lab 混合 + 变异；
- 花纹：反应-扩散/细胞自动机 + 对称；
- 稀有度：父母均值 + 变异；
- seeded。

## 4. 鱼纹

- 斑纹：细胞自动机 + 对称；
- 条纹：正弦扰动；
- 渐变：HSV 插值；
- 斑点：Poisson 采样；
- 生成一次缓存为纹理；
- 同 seed 一致。

## 5. 鱼缸（部分实现）

- 现在：6 个鱼位 + 底部沙地、水草、海星装饰（纯背景，不可编辑）；
- 未实现：装饰网格、鱼群 Boids、水质/饥饿/快乐。

## 6. 繁育（未实现）

- 两条鱼 → 1 条幼鱼；
- 冷却 4h；
- 需要食物；
- 幼鱼继承父母基因 + 变异；
- 图鉴记录。

## 7. 订单（已实现：6 个循环）

- 访客要「成熟鱼 N 条」，例如幼儿园参观、学堂观察课；
- 奖励王都币 + 繁荣度；
- 不做每日刷新、不做可刷新次数（避免刷单）。

## 9. 造景

- 装饰来自订单/繁荣度；
- 保存布局；

## 10. 双人

- 一人喂鱼、一人清理；
- 同屏分区；
- 共享鱼缸；
- 不实时联机。

## 11. 经济

- 鱼食：游戏币；
- 不卖稀有鱼；
- 广告后置：自愿加速。

## 15. 边界

- 鱼缸满 → 提示；
- 离线衰减上限 24h；
- 时钟回拨 → 单调时间；
- 存档损坏 → 重建；
- 低端机鱼群上限降低。

## 16. 测试

- 遗传分布；
- 鱼纹可复现；
- Boids 不崩溃；
- 订单可完成；
- 双人输入；
- 存档 migration。

## 17. 风险

- 鱼纹生成慢 → 缓存 + 预生成；
- 鱼群 AI 耗性能 → 上限/降级；
- 美术量大 → 模板 + 染色；
- 类目 → 休闲养鱼，无问题。
