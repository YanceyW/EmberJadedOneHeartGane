# 大厅：王都街区

## 1. 目标

- 3 秒进大厅，10 秒进游戏；
- 让用户知道「今天玩什么」；
- 承载长期 Meta：每日、收集、繁荣度、排行榜、双人；
- 不强制、不肝、不弹窗轰炸。

## 2. 布局（竖屏 750 设计宽）

```
┌──────────────────────────┐
│ 标题/名字/王都币/设置      │
├──────────────────────────┤
│   ← 可左右平移的平铺王都 →  │
│  仓库  花园      甜品屋    │
│       喷泉/国王王后        │
│   三消        水族馆       │
│   居民/长椅/花车/路灯      │
├──────────────────────────┤
│排行榜|每日|收集册|王都小铺 │
└──────────────────────────┘
```

- 大厅是**平铺地面 + 1800 宽世界**，默认视口 750；建筑沿用默认相机下的相对位置，围绕中央喷泉。
- 建筑分两类，走同一套 2.5D 深度排序：
  - **场馆**（`buildings`）：可加载分包进入的游戏；
  - **设施**（`facilities`）：不加载分包、直接开面板，例如西街的**王都仓库**。
- 单指左右拖动平移，双指捏合缩放 0.85–1.2；不做垂直平移、旋转或 3D。
- 世界坐标以屏幕中心为 0，命中测试统一走世界坐标（`townStructureAt` 同时覆盖场馆与设施）；平移/缩放不会改变点击逻辑。
- 建筑可点；未开放态用木牌「装修中」+ 微暗室内，不再搭满脚手架。
- 可游玩场馆显示暖窗、招牌摆动和星光；所有场馆/设施门口都不再挂「可游玩」徽章，只保留招牌与夜灯。
- 点击建筑 → 加载分包 → 进入；点国王/王后 → 打开「装扮」页；点仓库 → 打开仓库面板。
- 顶部 UI 使用 `capsuleBottom` 避开微信原生胶囊；原生「更多游戏」无法由游戏代码移除，只能避让/后台确认。
- 底部四个入口：排行榜、每日、收集册、王都小铺。
- 昼夜氛围按本地时间切换；天空/地面/建筑按阶段烘焙，招牌、烟、窗光、喷泉、居民、花瓣/萤火虫动态叠加。
- 居民只做无名环境 NPC，不显示名字、不可点击、不可换装。
- 视觉采用奶油纸雕 + Q 版 2 头身，详见 [ADR-0015](../decisions/ADR-0015-paper-storybook-visual-system.md) 与 [ADR-0016](../decisions/ADR-0016-pannable-town-world.md)。

- 底部四个入口：排行榜、每日委托、收集册、王都小铺。

## 3. 状态

| 状态 | 表现 |
|---|---|
| 未解锁 | 微暗室内 + 木牌「装修中」 |
| 可进入 | 正常 + 呼吸光 + 暖窗 |
| 有新内容 | 气泡 + 数字 |
| 加载中 | 建筑进度条 |
| 加载失败 | 重试按钮 |

## 4. Meta

### 每日委托

- 每天 3 单，来自 `shared/content/daily-orders.ts` 的固定池（面馆补货 / 花店补花 / 茶馆要茶 / 立春尝鲜…）；
- 按日期确定性抽取：同一天同一结果，不刷新、不重抽；
- **必须点「交付」才结算**：扣货 → 加王都币与繁荣度；不点就一直留着；
- 3 单全清额外 `+120 王都币 / +3 繁荣度`，并累计连续天数（断一天归零）；
- 缺货时按钮显示「缺货物」，提示去农场、加工屋或餐厅做；
- 每日 0 点按**本地日期**切换（`dayKey`），跨天自动重抽。

### 王都仓库（设施）

- 西街的木棚仓房，招牌「王都仓库」+ 木箱图标，夜里点两盏灯；
- 点开是仓库面板：7 个分页（基础 / 作物 / 花卉 / 牧产 / 半成品 / 茶饮 / 成菜）；
- 每格显示图形 + 数量 + 单价，点格子勾选要卖的；底部实时汇总「已选 N 种 · M 件 · +X 王都币」；
- `全选本类` / `清空` / `卖出选中`；顶部显示库存总价值与本类小计；
- 面板高度固定 800，关闭按钮固定在底部，短屏也不溢出。

### 收集册

- 花卉/鱼类/甜品/关卡星星；
- 按游戏分页；
- 收集度给繁荣度。

### 排行榜

- 首页底部「排行榜」入口，分类为：闯关 / 无尽 / 农场 / 花园 / 加工屋 / 水族馆 / 餐厅，不做周榜；
- **只展示名次与分数，不发王都币、不发繁荣度**；
- 每个玩家每款游戏只保留一条最高分，数据来自云函数 `leaderboard`；
- 显示「名次 / 王都居民名 / 分数」，不显示 openid；分数用 `1.2万 / 3.6亿` 压缩；
- 名字来自固定词库，设置里可随时换名；改名后排行榜显示当前名字；
- 离线或未登录时显示「离线模式，排行榜暂时不可用」。

### 王都币与小铺

- 王都币是**唯一**货币；旧「星尘」存档自动迁移。
- 获取：三消闯关每局/首通/三星、三消无尽按分数（封顶 60）；农场订单/卖作物；花园花单/卖花；加工屋加工单/卖成品/原料间；水族馆泡泡币/访客订单；餐厅营业额。
- 消费：
  - 王都建设：喷泉 / 街灯 / 花圃各 3 级；**购买后可在已解锁等级间自由切换**（低等级也可以选）；
  - 国王王后套装：默认礼服 / 花园 / 暖冬 / 星夜；
  - 三消图标：笑脸糖 / 交换糖 / 蜂蜜罐；
  - 三消方块皮肤：甜品屋（免费）/ 农场 180 / 王都食集 260；
  - 节日风格：春樱 / 灯会 / 秋收 / 暖冬；天气免费；
  - 农场种子/开地、花园花种、加工屋进货与烤面包、水族馆买鱼喂鱼。
- 只兑换外观，不卖时间/步数/分数/爆率；不抽卡、不内购。
- 小铺顶部显示余额；购买后自动装备并立即写 profile。
- 节日风格与天气可组合；天气在「天气」页切换，节日风格在「风格」页购买/切换。

### 场馆入口都在街上

- **底栏只放全局功能**：排行榜、每日、收集册、王都小铺；不放任何场馆快捷键；
- 农场、餐厅在东街，拖到右侧就能看到；仓库在三消西侧；
- 食材链路（农场 → 加工屋 → 餐厅）见 [economy-loop.md](./economy-loop.md)。

### 王都繁荣度

- 来源：首次通关、图鉴、每日、赛季；
- 只增不减；
- 阶段解锁装饰/称号；
- 不做数值压制。

### 双人广场

- 同屏小游戏入口；
- 三消接力/花园浇水/合成订单/喂鱼；
- 一台设备、两个触点；
- 对外「双人同乐/搭档」。

## 5. 设置/隐私

设置弹窗分三个标签：

### 声音

- 音乐、音效、震动；
- 音量/开关立即生效并持久化。

### 画面

- 画质：自动 / 高 / 中 / 低；
- 性能模式：强制低画质 + 关闭环境效果/场景动效/纸纹；
- 环境效果：花瓣、落叶、萤火虫、喷泉水花、烟；
- 场景动效：招牌摆动、角色呼吸、居民走动、猫尾；
- 纹理细节：纸纹/颗粒；
- 屏幕震动；
- 减少动效。

### 数据

- 隐私协议；
- 删除我的数据；
- 版本号；
- 不显示 openid。

## 6. 云

- 启动静默 login；
- 失败 → 游客；
- 排行榜离线显示「不可用」；
- 配置远程拉取，带缓存。

## 7. 事件

- `lobby_enter` / `lobby_exit`；
- `venue_click`（gameId）；
- `venue_load_fail`；
- `daily_claim`；
- `collection_open`；
- `duo_open`。

## 8. 边界

- 首次进入无存档 → 默认 profile；
- 云失败 → 不阻塞；
- 分包加载失败 → 重试 + 返回；
- 所有游戏未解锁 → 至少三消可玩；
- 低端机 → 减少装饰动画。

## 9. 测试

- 冷启动到大厅；
- 各场馆（含农场）进入/退出；
- 点西街仓库开面板 → 多选 → 卖出后币与库存都对；
- 每日面板点「交付」才扣货，缺货时按钮禁用；
- 左右平移边界与 0.85/1.2 缩放；
- 平移后建筑/设施/国王命中不漂移；
- 离线启动；
- 删除数据；
- 每日刷新；
- 安全区；
- 设置项持久化与即时生效；
- 低端机 FPS。

## 10. 风险

- 大厅太重 → 包体/性能：静态层烘焙 + 相机裁剪 + 粒子上限；
- 世界太宽 → 迷失：默认视口保留四馆，农场与餐厅在东街、仓库在西街，左右拖动可见；
- 入口太多 → 认知负担：底栏 4 个入口已接近上限，不再继续加；
- Meta 太肝 → 只做轻日常。
