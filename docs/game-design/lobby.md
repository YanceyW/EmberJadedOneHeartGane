# 大厅：王都街区

## 1. 目标

- 3 秒进大厅，10 秒进游戏；
- 让用户知道「今天玩什么」；
- 承载长期 Meta：每日、收集、繁荣度、排行榜、双人；
- 不强制、不肝、不弹窗轰炸。

## 2. 布局（竖屏 750 设计宽）

```
┌──────────────────────────┐
│ 标题/名字/王都币/设置      │
├──────────────────────────┤
│   ← 可左右平移的平铺王都 →  │
│   花园        甜品屋       │
│       喷泉/国王王后        │
│   三消        水族馆       │
│   居民/长椅/花车/路灯      │
├──────────────────────────┤
│排行榜|每日委托|收集册|小铺 │
└──────────────────────────┘
```

- 大厅是**平铺地面 + 1500 宽世界**，默认视口 750；四栋建筑沿用默认相机下的相对位置，围绕中央喷泉。
- 单指左右拖动平移，双指捏合缩放 0.85–1.2；不做垂直平移、旋转或 3D。
- 世界坐标以屏幕中心为 0，命中测试统一走世界坐标；平移/缩放不会改变建筑点击逻辑。
- 建筑可点；未开放态用木牌「装修中」+ 微暗室内，不再搭满脚手架。
- 三消可游玩态显示「可游玩」徽章、暖窗、招牌摆动和星光。
- 点击建筑 → 加载分包 → 进入；点国王/王后 → 打开「装扮」页。
- 顶部 UI 使用 `capsuleBottom` 避开微信原生胶囊；原生「更多游戏」无法由游戏代码移除，只能避让/后台确认。
- 底部四个入口：排行榜、每日委托、收集册、王都小铺。
- 昼夜氛围按本地时间切换；天空/地面/建筑按阶段烘焙，招牌、烟、窗光、喷泉、居民、花瓣/萤火虫动态叠加。
- 居民只做无名环境 NPC，不显示名字、不可点击、不可换装。
- 视觉采用奶油纸雕 + Q 版 2 头身，详见 [ADR-0015](../decisions/ADR-0015-paper-storybook-visual-system.md) 与 [ADR-0016](../decisions/ADR-0016-pannable-town-world.md)。

## 3. 状态

| 状态 | 表现 |
|---|---|
| 未解锁 | 微暗室内 + 木牌「装修中」 |
| 可进入 | 正常 + 呼吸光 +「可游玩」徽章 |
| 有新内容 | 气泡 + 数字 |
| 加载中 | 建筑进度条 |
| 加载失败 | 重试按钮 |

## 4. Meta

### 每日委托

- 3 个，来自不同游戏；
- 例如：三消完成 3 关、花园收获 5 朵、合成 10 次；
- 奖励王都币；
- 每日 0 点刷新（服务器时间）。

### 收集册

- 花卉/鱼类/甜品/关卡星星；
- 按游戏分页；
- 收集度给繁荣度。

### 排行榜

- 首页底部「排行榜」入口，一个排行榜按游戏分类（三消/花园/合成/水族馆），不做周榜；
- 每个玩家每款游戏只保留一条最高分，数据来自云函数 `leaderboard`；
- 显示「名次 / 王都居民名 / 分数」，不显示 openid；
- 名字来自固定词库，设置里可随时换名；改名后排行榜显示当前名字；
- 离线或未登录时显示「离线模式，排行榜暂时不可用」。

### 王都币与小铺

- 王都币是唯一通用货币；旧「星尘」存档自动迁移。
- 获取：三消每局、首通、三星、每日挑战；后续每日委托/最高分榜/其他游戏。
- 消费：
  - 王都建设：喷泉 / 街灯 / 花圃各 3 级；
  - 国王王后套装：默认礼服 / 花园 / 暖冬 / 星夜；
  - 三消图标：笑脸糖 / 交换糖 / 蜂蜜罐。
- 只兑换外观，不卖时间/步数/分数/爆率；不抽卡、不内购。
- 小铺顶部显示余额；购买后自动装备并立即写 profile。

### 王都繁荣度

- 来源：首次通关、图鉴、每日、赛季；
- 只增不减；
- 阶段解锁装饰/称号；
- 不做数值压制。

### 排行榜

- 最高分榜（三消分数/花园收集/合成订单/水族馆访客）；
- 只显示昵称（默认「小国王」）+ 分数；
- 不做陌生人社交。

### 双人广场

- 同屏小游戏入口；
- 三消接力/花园浇水/合成订单/喂鱼；
- 一台设备、两个触点；
- 对外「双人同乐/搭档」。

## 5. 设置/隐私

设置弹窗分三个标签：

### 声音

- 音乐、音效、震动；
- 音量/开关立即生效并持久化。

### 画面

- 画质：自动 / 高 / 中 / 低；
- 性能模式：强制低画质 + 关闭环境效果/场景动效/纸纹；
- 环境效果：花瓣、落叶、萤火虫、喷泉水花、烟；
- 场景动效：招牌摆动、角色呼吸、居民走动、猫尾；
- 纹理细节：纸纹/颗粒；
- 屏幕震动；
- 减少动效。

### 数据

- 隐私协议；
- 删除我的数据；
- 版本号；
- 不显示 openid。

## 6. 云

- 启动静默 login；
- 失败 → 游客；
- 排行榜离线显示「不可用」；
- 配置远程拉取，带缓存。

## 7. 事件

- `lobby_enter` / `lobby_exit`；
- `venue_click`（gameId）；
- `venue_load_fail`；
- `daily_claim`；
- `collection_open`；
- `duo_open`。

## 8. 边界

- 首次进入无存档 → 默认 profile；
- 云失败 → 不阻塞；
- 分包加载失败 → 重试 + 返回；
- 所有游戏未解锁 → 至少三消可玩；
- 低端机 → 减少装饰动画。

## 9. 测试

- 冷启动到大厅；
- 四场馆进入/退出；
- 左右平移边界与 0.85/1.2 缩放；
- 平移后建筑/国王命中不漂移；
- 离线启动；
- 删除数据；
- 每日刷新；
- 安全区；
- 设置项持久化与即时生效；
- 低端机 FPS。

## 10. 风险

- 大厅太重 → 包体/性能：静态层烘焙 + 相机裁剪 + 粒子上限；
- 世界太宽 → 迷失：默认视口保留四馆，平移提示只出现一次；
- 入口太多 → 认知负担：首屏 4 个，更多滚动；
- Meta 太肝 → 只做轻日常。
