# 大厅：王都街区

## 1. 目标

- 3 秒进大厅，10 秒进游戏；
- 让用户知道「今天玩什么」；
- 承载长期 Meta：每日、收集、繁荣度、排行榜、双人；
- 不强制、不肝、不弹窗轰炸。

## 2. 布局（竖屏 750×1334）

```
┌──────────────────────────┐
│ 顶部：头像/名字/星尘/设置  │
├──────────────────────────┤
│                          │
│   王都街区（可滚动）       │
│   [三消]  [花园]          │
│   [合成]  [水族馆]        │
│                          │
│   喷泉/小猫/花瓣（装饰）    │
├──────────────────────────┤
│ 每日委托 | 收集册 | 双人广场│
└──────────────────────────┘
```

- 场馆卡片：建筑插画 + 招牌 + 进度气泡 + 锁定态；
- 点击 → 加载分包 → 进入；
- 首次进入显示 3 秒提示；
- 长按显示简介。

## 3. 状态

| 状态 | 表现 |
|---|---|
| 未解锁 | 灰色 + 条件 |
| 可进入 | 正常 + 呼吸光 |
| 有新内容 | 气泡 + 数字 |
| 加载中 | 建筑进度条 |
| 加载失败 | 重试按钮 |

## 4. Meta

### 每日委托

- 3 个，来自不同游戏；
- 例如：三消完成 3 关、花园收获 5 朵、合成 10 次；
- 奖励星尘；
- 每日 0 点刷新（服务器时间）。

### 收集册

- 花卉/鱼类/甜品/关卡星星；
- 按游戏分页；
- 收集度给繁荣度。

### 王都繁荣度

- 来源：首次通关、图鉴、每日、赛季；
- 只增不减；
- 阶段解锁装饰/称号；
- 不做数值压制。

### 排行榜

- 周榜（三消分数/花园收集/合成订单/水族馆访客）；
- 只显示昵称（默认「小国王」）+ 分数；
- 不做陌生人社交。

### 双人广场

- 同屏小游戏入口；
- 三消接力/花园浇水/合成订单/喂鱼；
- 一台设备、两个触点；
- 对外「双人同乐/搭档」。

## 5. 设置/隐私

- 音乐/音效/震动；
- 隐私协议；
- 删除我的数据；
- 版本号；
- 不显示 openid。

## 6. 云

- 启动静默 login；
- 失败 → 游客；
- 排行榜离线显示「不可用」；
- 配置远程拉取，带缓存。

## 7. 事件

- `lobby_enter` / `lobby_exit`；
- `venue_click`（gameId）；
- `venue_load_fail`；
- `daily_claim`；
- `collection_open`；
- `duo_open`。

## 8. 边界

- 首次进入无存档 → 默认 profile；
- 云失败 → 不阻塞；
- 分包加载失败 → 重试 + 返回；
- 所有游戏未解锁 → 至少三消可玩；
- 低端机 → 减少装饰动画。

## 9. 测试

- 冷启动到大厅；
- 四场馆进入/退出；
- 离线启动；
- 删除数据；
- 每日刷新；
- 安全区；
- 低端机 FPS。

## 10. 风险

- 大厅太重 → 包体/性能：装饰程序化 + 缓存；
- 入口太多 → 认知负担：首屏 4 个，更多滚动；
- Meta 太肝 → 只做轻日常。
