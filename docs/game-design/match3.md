# 王都三消

## 1. 核心

6×8 棋盘，**滑动**交换相邻方块，3 连消除；**固定 3 分钟倒计时 + 目标分数逐关上涨**。

棋盘只认滑动：点击方块不选中、不交换；HUD 与结算按钮仍可点击。

**目标达成不是回合结束**：达到目标只锁 1 星并解锁下一关，计时继续，玩家可以继续打到 1.25x / 1.5x 冲 2/3 星，或点「提前结算」立即收尾。

只有两个模式：

| 模式 | 规则 | 结算 | 排行榜 |
|---|---|---|---|
| 闯关 | 10 关，每关 180 秒，目标分逐关上涨 | 时间到或提前结算；冲 2/3 星 | `match3-campaign` |
| 无时间限制 | **不计时、不限步数**，想玩多久玩多久 | 随时退出结算 | `match3-endless` |

「无时间限制」就是字面意思：没有时钟、没有步数，HUD 用正计时显示玩了多久；想走就从「模式」或返回键退出，按当前分数结算。长局分数会很大，UI 统一压缩成 `1.2万 / 3.6亿`。

## 2. 一局流程

```
进入 → 模式选择（闯关 / 无时间限制 + 方块皮肤）
→ 棋盘逐行落入（约 0.35s）
→ 闯关：开始 180s 倒计时；无尽：开始正计时
→ 滑动交换 → 消除/连锁 → 2 秒内接续触发节奏加成
→ 达标：锁 1 星 + 解锁下一关，计时继续冲 2/3 星
→ 时间到 / 提前结算 / 主动退出 → 结算（星级/奖励）→ 下一关 / 重试 / 选择模式
→ 未达目标：时间到失败
```

## 3. 输入

- 按下方块：上浮 6%、光环、轻 `press` 音，但不锁定选中。
- 滑动阈值 22 设计像素；取位移更大的轴判断方向。
- 起点格与目标相邻格交换；越界 / 空格 / 无三连 → 约 12% 格宽回弹 + `invalid` + `dust`。
- 动画期间忽略新滑动（不排队），避免消除过程中误执行。
- 每局前 6 秒在棋盘下提示「滑动交换相邻方块」，首次有效滑动后立即消失。
- 棋盘点击完全忽略；返回、模式、结算按钮仍使用点击。

## 4. 棋盘

- 6 行 × 8 列（可配）；
- 每局固定 5 种基础块，外观取「当前装备的方块皮肤」（见第 7 节）；
- 特殊块（后续）：炸弹（4 连）、彩虹（5 连）、十字（L/T）；
- 障碍（后续）：冰块（1–2 层）、木箱、空洞；
- 表现层保持正视矩形格：预烘焙挤出侧边、顶面高光、落地阴影、下落近大远小与挤压，不改玩法坐标系（ADR-0011）。

## 5. 生成

- 初始棋盘无自动三连；
- **反向生成**：先放目标/障碍，再填充；
- 至少一个可解交换；
- 无可解 → 重排（保留障碍），并清空当前节奏档位；
- 闯关与无尽都使用时间种子，重开即新棋盘。

## 6. 计时与目标

| 项 | 值 |
|---|---|
| 闯关时长 | 180 秒 |
| 无尽计时 | 正计时，不封顶 |
| 开始 | 棋盘入场动画结束后开始，避免开局白丢时间 |
| 动画期间 | 计时继续（只切后台暂停） |
| 警告 | ≤30s 数字转 `coral`；≤10s 数字脉动 + 每秒 `tick` |
| 达标 | 不结束：锁 1 星、解锁下一关，继续冲 2/3 星 |
| 结束 | 时间归零或点「提前结算」；归零时正在消除则等本段播完再判定 |
| 失败 | 时间归零且未达目标；归零瞬间已达标则按胜利结算 |

星级沿用 `starsFor`：1x / 1.25x / 1.5x。顶部进度条按 **0 → 1.5x 目标** 铺满，三颗星分别标在 1x / 1.25x / 1.5x 位置；右侧文案显示「距过关 / 距 N 星还差多少分」，不再用会与条长对不上的百分比。

## 7. 方块皮肤（王都小铺出售）

方块是「王都里端上来的东西」，但**不再跟关卡自动切换，而是在王都小铺「方块」页购买并装备**。闯关和无时间限制共用当前皮肤。

| 皮肤 | 场馆 | 价格 | 5 个方块 |
|---|---|---|---|
| `sweets` | 王都甜品屋 | 免费 | 莓果 / 蜂蜜罐 / 薄荷糖 / 马卡龙 / 花瓣糖 |
| `farm` | 王都农场 | 180 王都币 | 胡萝卜 / 莓果 / 蜂蜜罐 / 花瓣 / 麦穗 |
| `town` | 面包房 · 食集 | 260 王都币 | 面包 / 胡萝卜 / 蜂蜜罐 / 薄荷糖 / 马卡龙 |

- 共用 8 个预烘焙精灵（`tile-berry / tile-honey / tile-mint / tile-sky / tile-lilac / tile-carrot / tile-bread / tile-wheat`）。
- 只换外观，不改 3 连规则、颜色数量与难度；已购买的皮肤可在模式页随时切换。
- 区分不靠颜色堆叠：每个精灵同时有**独立轮廓**（方罐 / 三角胡萝卜 / 圆面包 / 麦穗 / 花形）、**底纹**（条纹 / 圆点 / 麦粒 / 糖屑）和色相；灰度或色弱下也能配对。
- 新皮肤接入：先在 `shared/content/tile-skins.ts` 里组 5 个精灵并定价；要新精灵先扩精灵表并保持 `ATLAS_W = 128 × 方块数`。

## 8. 节奏加成（跨操作）

- **判定窗口**：距上一次成功交换开始 ≤ 2.0 秒。
- **档位**：1–6 档。
- **倍率**：`1 + 0.15 × (档位 - 1)`，即 ×1.00 → ×1.75。
- **作用范围**：该次交换产生的所有连锁段都乘该倍率。
- **连锁倍率**仍为 `消除格数 × 10 × 连锁段`，节奏倍率在游戏层相乘，棋盘系统保持纯逻辑。
- **音高**：`(连锁段 - 1 + 节奏档位 - 1) × 2` 半音，封顶 +12；沿用 `feedback.match(..., tempoStep)`。
- **粒子**：`sparkle` 随连锁 + 节奏放大，封顶 2.2；节奏达到 3 / 6 档时额外放一次 `ring`。
- **飘字**：节奏生效时 `gold`，普通时 `jade`。
- **重置**：换局、时间到、死局重排清零；非法滑动不直接清零，交给 2 秒窗口自然衰减。

## 9. 连锁 / 特殊

- 4 连 → 炸弹；
- 5 连 → 彩虹；
- L/T → 十字；
- 特殊组合：
  - 炸弹 + 炸弹：3×3；
  - 彩虹 + 彩虹：全屏同色；
  - 彩虹 + 炸弹：消除一类；
- 连锁倍率：1x / 1.5x / 2x / 3x（与节奏倍率叠加）。

## 11. 关卡包

- 当前实现 10 关（`data/levels.ts`），最终目标 30 关；
- 每 10 关一个大关卡包主题；方块外观由玩家装备的皮肤决定（见第 7 节）；
- 每关 3 星（1x / 1.25x / 1.5x 目标）；
- 星级累计解锁装饰/称号；
- 通关解锁下一关，可重玩刷星。

## 12. 双模式与排行榜

- **闯关**：默认进入上次进度；结算记录 `bestScore`、星级、解锁下一关；排行榜 id `match3-campaign`。
- **无时间限制**：不计时、不限步数；连锁/节奏照常；退出时结算并记录 `endlessBest` / `endlessBestSeconds`；排行榜 id `match3-endless`。
- 排行榜在大厅「排行榜」里拆成「闯关 / 无尽」两个子项，其余场馆各一项（只展示，不发王都币）。
- 两个模式都只提交本模式最高分；云函数按 `gameId` 分开存储，互不覆盖。
- 退出无尽模式时按当前分数结算，不会丢已打出的成绩。

## 13. 双人接力

- 同屏上下分区（或轮流）；
- 一人一步，共享目标与倒计时；
- 轮到谁高亮谁；
- 不实时联机；
- 结算显示双方贡献。

## 14. 经济

- 星星 → 繁荣度；
- 闯关王都币：每局按分数/目标给币，33%/66%/100% 三档宝箱；首通 +20、首次三星 +10；失败给少量参与币；
- 无时间限制：`4 + 分数 / 150`，封顶 60 币；不参与首通/三星奖励；长局不会无限印钱；
- 王都币只能在大厅小铺兑换外观（建设/国王王后套装/图标套/方块皮肤），不卖时间、步数、分数或道具；
- 广告后置：自愿额外奖励。

## 15. UI

- 首次进入先显示**模式选择**：闯关 / 无时间限制两张卡 + 方块皮肤切换；返回键离开场馆；
- 对局顶部：返回图标 / 标题 / 模式；使用胶囊安全区，避免原生「更多游戏」遮挡；
- 达成目标后「提前结算」出现在「模式」下方，随对局结束消失；
- 信息卡：分数 + 节奏条；闯关显示剩余时间（`mm:ss`，警告态脉动），无尽显示**已用时间**（正计时，超过 1 小时自动 `h:mm:ss`）+「交换 N 次 · 随时退出结算」；
- 棋盘居中；闯关显示三星进度条（0 → 1.5x 目标，三颗星刻度）+「距过关 / 距 N 星」文案；无尽不显示星级条；
- 下半屏「王都共鸣」：6 档节奏仪表、王都币奖励轨、国王+王后双人舞台、王都剪影/喷泉；无尽模式的奖励轨改为「按本局分数结算」；
- 短屏自动紧凑：缩小舞台、隐藏剪影，只保留仪表/奖励轨/双人；
- 结算：闯关显示星级，无尽显示「新纪录 / 最高分」胶囊；`+N 王都币` / 余额 / 下一关（仅闯关）/ 重玩 / 选择模式；
- 模式选择在高屏时底部补一张牌桌（当前皮肤方块散在桌上），避免大片留白；短屏自动省略；
- 统一 design-system；场馆图标为 2D 平面，局内方块用颜色+轮廓+纹理三重区分。

## 16. 存档

```ts
interface Match3Save {
  schemaVersion: 5;
  bestScore: number;          // 闯关最高分
  endlessBest: number;        // 无时间限制最高分
  endlessBestSeconds: number; // 无时间限制单局最长用时（秒）
  wins: number;
  unlockedLevel: number;
  stars: Record<string, number>;
}
```

存档迁移：

- v1 → v2：补 `unlockedLevel: 1`、`stars: {}`；
- v2 → v3：补每日字段（已废弃）；
- v3 → v4：移除 `dailyDate/dailyBest`，补 `endlessBest: 0`；旧每日进度不再读取；
- v4 → v5：补 `endlessBestSeconds: 0`（无时间限制取消步数后的新展示字段）；
- 迁移函数在 `systems/save.ts`，有单测；
- 节奏档位、已用时间、交换次数属于单局状态，不入存档。

## 18. 边界

- 无可行交换 → 重排并清空节奏；
- 棋盘全空 → 补充；
- 达标时还有剩余时间 → 继续冲星，星级实时落盘；点「提前结算」或时间到才结束；
- 冲星途中点返回 → 已达标按胜利结算，首通奖励与星级不丢；
- 时间归零但正在消除 → 播完本段再判定，若已达标则胜利；
- 无尽模式退出时还在连锁 → 先播完本段再结算；
- 无尽模式主动离开 → 按当前分数结算并提交；
- 切后台 → 暂停计时/节奏窗口；
- 存档损坏 → 重建。

## 19. 测试

- 生成 1000 局无初始三连；
- 每局至少一个可解交换；
- 消除/连锁/特殊块单测；
- 死局重排；
- 节奏窗口 / 倍率 / 音高 / 封顶 / 重置；
- 倒计时递减、警告阈值、归零判定；
- 星级门槛（1x / 1.25x / 1.5x）、进度条比例；
- 方块皮肤价格/唯一精灵/回退；
- 闯关与无尽最高分分开合并；
- 纯滑动输入序列（touchstart → move 触发交换，touchend 不产生点击交换）；
- 双人输入序列；
- 存档 migration。

## 20. 风险

- 关卡设计成本 → 生成器 + 手工校验；
- 特殊块组合爆炸 → 限制组合表；
- 低端机特效 → 粒子上限/降级；
- 3 分钟 + 节奏倍率抬高分数上限 → 先按当前数值上线，再用真机数据微调倍率步长与目标；
- 类目 → 纯休闲消除，无问题。
