# 王都三消

## 1. 核心

6×8 棋盘，**滑动**交换相邻方块，3 连消除；**固定 3 分钟倒计时 + 目标分数逐关上涨**。

棋盘只认滑动：点击方块不选中、不交换；HUD 与结算按钮仍可点击。

## 2. 一局流程

```
进入 → 棋盘逐行落入（约 0.35s）→ 开始 180s 倒计时
→ 滑动交换 → 消除/连锁 → 2 秒内接续触发节奏加成
→ 达到目标立即结算 / 时间到未达目标失败
→ 结算（星级/奖励）→ 下一关 / 重试 / 返回
```

## 3. 输入

- 按下方块：上浮 6%、光环、轻 `press` 音，但不锁定选中。
- 滑动阈值 22 设计像素；取位移更大的轴判断方向。
- 起点格与目标相邻格交换；越界 / 空格 / 无三连 → 约 12% 格宽回弹 + `invalid` + `dust`。
- 动画期间忽略新滑动（不排队），避免消除过程中误执行。
- 每局前 6 秒在棋盘下提示「滑动交换相邻方块」，首次有效滑动后立即消失。
- 棋盘点击完全忽略；返回、每日、结算按钮仍使用点击。

## 4. 棋盘

- 6 行 × 8 列（可配）；
- 5 种基础块：莓果 / 蜂蜜 / 薄荷糖 / 马卡龙 / 花瓣糖；
- 特殊块（后续）：炸弹（4 连）、彩虹（5 连）、十字（L/T）；
- 障碍（后续）：冰块（1–2 层）、木箱、空洞；
- 表现层保持正视矩形格：预烘焙挤出侧边、顶面高光、落地阴影、下落近大远小与挤压，不改玩法坐标系（ADR-0011）。

## 5. 生成

- 初始棋盘无自动三连；
- **反向生成**：先放目标/障碍，再填充；
- 至少一个可解交换；
- 无可解 → 重排（保留障碍），并清空当前节奏档位；
- 每日挑战固定 seed。

## 6. 计时与目标

| 项 | 值 |
|---|---|
| 每关时长 | 180 秒（全部关卡、每日挑战一致） |
| 开始 | 棋盘入场动画结束后开始，避免开局白丢时间 |
| 动画期间 | 计时继续（只切后台暂停） |
| 警告 | ≤30s 数字转 `coral`；≤10s 数字脉动 + 每秒 `tick` |
| 结束 | 达标立即胜利；时间归零且未达标失败；归零时正在消除则等本段播完再判定 |

| 2 | 1800 | 2700 |

## 7. 节奏加成（跨操作）

- **判定窗口**：距上一次成功交换开始 ≤ 2.0 秒。
- **档位**：1–6 档。
- **倍率**：`1 + 0.15 × (档位 - 1)`，即 ×1.00 → ×1.75。
- **作用范围**：该次交换产生的所有连锁段都乘该倍率。
- **连锁倍率**仍为 `消除格数 × 10 × 连锁段`，节奏倍率在游戏层相乘，棋盘系统保持纯逻辑。
- **音高**：`(连锁段 - 1 + 节奏档位 - 1) × 2` 半音，封顶 +12；沿用 `feedback.match(..., tempoStep)`。
- **粒子**：`sparkle` 随连锁 + 节奏放大，封顶 2.2；节奏达到 3 / 6 档时额外放一次 `ring`。
- **飘字**：节奏生效时 `gold`，普通时 `jade`。
- **重置**：换局、时间到、死局重排清零；非法滑动不直接清零，交给 2 秒窗口自然衰减。

## 8. 连锁 / 特殊

- 4 连 → 炸弹；
- 5 连 → 彩虹；
- L/T → 十字；
- 特殊组合：
  - 炸弹 + 炸弹：3×3；
  - 彩虹 + 彩虹：全屏同色；
  - 彩虹 + 炸弹：消除一类；
- 连锁倍率：1x / 1.5x / 2x / 3x（与节奏倍率叠加）。

## 10. 关卡包

- 当前实现 10 关（`data/levels.ts`），最终目标 30 关；
- 每 10 关一个主题；
- 每关 3 星（1x / 1.25x / 1.5x 目标）；
- 星级累计解锁装饰/称号；
- 通关解锁下一关，可重玩刷星。

## 11. 每日挑战

- 固定 seed（`dailySeed(date)`，日期变化棋盘变化）；
- 固定 180 秒 / 目标 4000；
- 头部「每日」按钮进入；
- 失败可重试，记录当日最佳；
- 排名奖励后续接入；完成每日挑战给王都币。

## 12. 双人接力

- 同屏上下分区（或轮流）；
- 一人一步，共享目标与倒计时；
- 轮到谁高亮谁；
- 不实时联机；
- 结算显示双方贡献。

## 13. 经济

- 星星 → 繁荣度；
- 王都币：每局按分数/目标给币，33%/66%/100% 三档宝箱；
- 首通 +20、首次三星 +10、每日挑战完成 +30；失败给少量参与币；
- 王都币只能在大厅小铺兑换外观（建设/国王王后套装/图标套），不卖时间、步数、分数或道具；
- 广告后置：自愿额外奖励。

## 14. UI

- 顶部：返回图标 / 标题 / 每日；使用胶囊安全区，避免原生「更多游戏」遮挡；
- 信息卡：分数 + 节奏条、剩余时间（`mm:ss`，警告态脉动）；
- 棋盘居中；下方目标进度条；
- 下半屏「王都共鸣」：6 档节奏仪表、王都币奖励轨、国王+王后双人舞台、王都剪影/喷泉；
- 短屏自动紧凑：缩小舞台、隐藏剪影，只保留仪表/奖励轨/双人；
- 结算：星级 / 得分 / `+N 王都币` / 余额 / 下一关 / 重玩 / 返回；
- 统一 design-system；场馆图标为 2D 平面，局内方块用颜色+轮廓+纹理三重区分。

## 15. 存档

```ts
interface Match3Save {
  schemaVersion: 3;
  bestScore: number;
  wins: number;
  unlockedLevel: number;
  stars: Record<string, number>;
  dailyDate: string;
  dailyBest: number;
}
```

存档迁移：

- v1（`bestScore`/`wins`）→ v2：补 `unlockedLevel: 1`、`stars: {}`；
- v2 → v3：补 `dailyDate: ''`、`dailyBest: 0`；
- 迁移函数在 `systems/save.ts`，有单测；
- 节奏档位与剩余时间属于单局状态，不入存档。

## 16. 事件

- `level_start/complete/fail`（complete/fail 带 `tempoMax`、`secondsLeft` / `reason: 'time'`）；
- `daily_start/complete/fail`；
- `duo_start/complete`；
- `powerup_use`；
- `reshuffle`。

## 17. 边界

- 无可行交换 → 重排并清空节奏；
- 棋盘全空 → 补充；
- 达标时还有剩余时间 → 立即结算；
- 时间归零但正在消除 → 播完本段再判定，若已达标则胜利；
- 切后台 → 暂停计时；
- 存档损坏 → 重建。

## 18. 测试

- 生成 1000 局无初始三连；
- 每局至少一个可解交换；
- 消除/连锁/特殊块单测；
- 死局重排；
- 每日 seed 一致；
- 节奏窗口 / 倍率 / 音高 / 封顶 / 重置；
- 倒计时递减、警告阈值、归零判定；
- 纯滑动输入序列（touchstart → move 触发交换，touchend 不产生点击交换）；
- 双人输入序列；
- 存档 migration。

## 19. 风险

- 关卡设计成本 → 生成器 + 手工校验；
- 特殊块组合爆炸 → 限制组合表；
- 低端机特效 → 粒子上限/降级；
- 3 分钟 + 节奏倍率抬高分数上限 → 先按当前数值上线，再用真机数据微调倍率步长与目标；
- 类目 → 纯休闲消除，无问题。
