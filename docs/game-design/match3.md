# 王都三消

## 1. 核心

6×8 棋盘，交换相邻，3 连消除；步数 + 目标双约束。

## 2. 一局流程

```
进入 → 显示目标/步数 → 操作 → 消除/连锁 → 目标达成/步数用尽
→ 结算（星星/奖励）→ 下一关/重试/返回
```

## 3. 棋盘

- 6 行 × 8 列（可配）；
- 5–6 种基础块；
- 块类型：莓果/星星/蜂蜜/花瓣/糖霜；
- 特殊块：炸弹（4 连）、彩虹（5 连）、十字（L/T）；
- 障碍：冰块（1–2 层）、木箱、空洞。

## 4. 生成

- 初始棋盘无自动三连；
- **反向生成**：先放目标/障碍，再填充；
- 至少一个可解交换；
- 无可解 → 重排（保留障碍）；
- 每日挑战固定 seed。

## 5. 目标

- 收集 N 个某块；
- 清除所有冰块/木箱；
- 达到分数；
- 限时（少量关卡）。

## 6. 连锁/特殊

- 4 连 → 炸弹；
- 5 连 → 彩虹；
- L/T → 十字；
- 特殊组合：
  - 炸弹+炸弹：3×3；
  - 彩虹+彩虹：全屏同色；
  - 彩虹+炸弹：消除一类；
- 连锁倍率：1x/1.5x/2x/3x。

## 7. 难度

| 难度 | 目标 | 障碍 | 颜色 |
|---|---|---|---|
| 1 | 少 | 无 | 5 |
| 2 | 中 | 少量 | 5 |
| 3 | 多 | 中 | 6 |
| 4 | 多 | 多 | 6 |
| 5 | 极限 | 多 | 6 + 限时 |

## 8. 关卡包

- 当前实现 10 关（`data/levels.ts`），最终目标 30 关；
- 每 10 关一个主题；
- 每关 3 星（目标分 / 1.25 倍 / 1.5 倍）；
- 星级累计解锁装饰/称号；
- 通关解锁下一关，可重玩刷星。

## 9. 每日挑战

- 固定 seed（`dailySeed(date)`，日期变化棋盘变化）；
- 20 步 / 目标 1500；
- 头部「每日」按钮进入；
- 失败可重试，记录当日最佳；
- 排名/星尘奖励后续接入。

## 10. 双人接力

- 同屏上下分区（或轮流）；
- 一人一步，共享目标；
- 轮到谁高亮谁；
- 不实时联机；
- 结算显示双方贡献。

## 11. 经济

- 星星 → 繁荣度；
- 星尘 → 大厅装饰；
- 不卖步数、不卖道具（首发）；
- 广告后置：自愿额外奖励。

## 12. UI

- 顶部：目标/步数/分数；
- 棋盘居中；
- 底部：道具/返回/设置；
- 结算：星级/奖励/再来一次；
- 统一 design-system。

## 13. 存档

```ts
interface Match3Save {
  schemaVersion: 3;
  bestScore: number;
  wins: number;
  unlockedLevel: number;
  stars: Record<string, number>;
  dailyDate: string;
  dailyBest: number;
}
```

存档迁移：

- v1（`bestScore`/`wins`）→ v2：补 `unlockedLevel: 1`、`stars: {}`；
- v2 → v3：补 `dailyDate: ''`、`dailyBest: 0`；
- 迁移函数在 `systems/save.ts`，有单测。

## 14. 事件

- `level_start/complete/fail`；
- `daily_start/complete`；
- `duo_start/complete`；
- `powerup_use`；
- `reshuffle`。

## 15. 边界

- 无可行交换 → 重排；
- 棋盘全空 → 补充；
- 步数用尽但目标完成 → 胜利；
- 目标完成但还有步数 → 结算奖励；
- 切后台 → 暂停计时；
- 存档损坏 → 重建。

## 16. 测试

- 生成 1000 局无初始三连；
- 每局至少一个可解交换；
- 消除/连锁/特殊块单测；
- 死局重排；
- 每日 seed 一致；
- 双人输入序列；
- 存档 migration。

## 17. 风险

- 关卡设计成本 → 生成器 + 手工校验；
- 特殊块组合爆炸 → 限制组合表；
- 低端机特效 → 粒子上限/降级；
- 类目 → 纯休闲消除，无问题。
