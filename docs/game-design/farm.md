# 王都农场

> 状态：可玩原型（`src/games/farm`，分包 `farm`）。
> 定位：食材生产，不与「王都花园」的花卉收集重叠。

## 1. 核心

买种子 → 播种 → 等成熟 → 收获 → 交订单/卖仓库 → 买更多种子/开地。

## 2. 和花园的区别

| 项目 | 王都农场 | 王都花园 |
|---|---|---|
| 主题 | 食材 | 花卉 |
| 产出 | 18 种作物（小白菜 → 葡萄） | 9 种花（雏菊 → 荷花） |
| 主要去向 | 加工屋半成品、餐厅备菜/营业解锁、订单、仓库卖 | 花单、花茶、营业解锁、仓库卖 |
| 随机 | 固定作物、固定价格 | 固定花种、固定价格 |
| 目标 | 稳定食材与订单 | 收集与陈列 |

> 两边的产出都进**王都仓库**（`profile.pantry`），只是分类不同（作物 / 花卉），见 [economy-loop.md](./economy-loop.md)。

## 3. 原型规则

- **3×3 共 9 块地**：初始开垦 6 块，后 3 块用王都币扩建（60 / 100 / 160）；只能按顺序开，未轮到的显示「待开垦」；
- 18 种作物，成熟 20s–120s，分 4 档节奏：20–35s（小白菜/小麦/水稻）、40–60s（大豆/番茄/白萝卜/胡萝卜/黄瓜/大蒜）、65–85s（草莓/土豆/洋葱/玉米/大白菜）、95–120s（蘑菇/南瓜/茄子/葡萄）；
- 种子用王都币购买，播种即扣费；同一块地成熟前不能重复种；
- 离线按真实时间生长，不死亡；
- 单块点收，或「一键收获」把所有成熟地块一次收进**王都仓库**（`profile.pantry`）；
- 收获进仓库后，可「卖出全部」、交当前订单，或留给加工屋做半成品、餐厅备菜；
- 每种作物第一次收获会写入 `profile.ingredientUnlocks`，永久解锁餐厅营业的对应原材料供应；解锁后卖光也不回退；
- 订单 8 个循环：面粉、胡萝卜、南瓜饼、时蔬沙拉、葡萄拼盘、酸菜、菌菇、根菜；
- 订单给王都币 + 繁荣度；
- 作物不卖真实货币，不抽卡，不做偷菜/社交。

## 5. UI

- 顶部：返回、标题、王都币；
- 田地前的小景：风车、谷仓、树、篱笆，把首页王都的纸雕语言延伸进来；
- 中部：**3×3 方块田地**（QQ 农场式），每块有木框、土面、田垄和石子；
  - 空地：虚线「＋」+「点一下种<当前种子>」+ 种子价；
  - 生长：作物按阶段变大 + 剩余秒数 + 进度条；
  - 成熟：作物轻晃、金色光环、「可收获」标签、满格进度条；
  - 锁定：草皮底 + 锁；下一块显示价格，后面的显示「待开垦」；
- 种子栏：18 张种子包排成 5 列 × 4 行（紧凑卡：作物 + 种子价 + 仓库持有量），选中的有金色描边；
- 订单卡：需求/持有/奖励 + 交付按钮；
- 底部三键：一键收获 / 卖出全部 / 开垦土地；
- 统一纸雕 UI 与作物画法（`view/crop-art.ts`），见 `docs/visual-style.md`。

## 6. 存档

```ts
interface FarmSave {
  schemaVersion: 2;
  plots: Array<{ cropId: string; plantedAt: number } | null>;
  plotsUnlocked: number;
  orderIndex: number;
  totalHarvests: number;
  totalCoins: number;
}
```

- key：`save:farm`；
- **v2 起农场不再自带库存**：作物统一放在 `profile.pantry`（王都仓库），加工屋和餐厅读同一份；
- v1 存档的 `inventory` 由 `legacyInventory()` 读出，进场时一次性并进仓库并改写存档；
- migration 在 `src/games/farm/systems/farm.ts`；
- 收获/购买/订单后立即写本地；
- 后续可接云同步，当前原型不依赖云。

## 7. 后续

- 季节作物（春/夏/秋/冬）；
- 加工屋半成品与餐厅备菜已经接通（小麦 → 面粉 → 馒头/挂面 → 成菜）；
- 农场装饰（栅栏、稻草人、风车）；
- 花园与农场共享「土地等级」外观，但不共享产出；
- 不做偷菜、排行榜攀比、真实货币交易。

## 8. 测试

- 播种/生长/收获时间边界；
- 锁定土地、按顺序扩建、9 块封顶；
- 一键收获只收成熟地块；
- 订单可完成/不可完成；
- 卖出价格；
- 存档 migration（旧 6 块存档补 3 块锁定地）；
- 离线成熟；
