# 王都牧场

> 状态：**可玩原型**（`src/games/ranch`，分包 `ranch`）。
> 定位：用饲料换肉蛋奶，接在农场/加工屋与餐厅之间。

## 1. 核心循环

```
加工屋配饲料（玉米 + 小麦）
        │
        ▼
牧场喂动物 → 等待产出 → 收取鸡蛋/牛奶/猪肉/羊肉
        │
        ▼
王都仓库 → 餐厅备料台/3×3 灶台做牧产菜（番茄炒蛋、卤肉面、四宝汤面等）
```

## 2. 四个分区

| 畜栏 | 动物 | 产物 | 产出时间 | 买入价 |
|---|---|---|---|---|
| 鸡栏 | 母鸡 | 鸡蛋 | 26s | 120 起 |
| 牛栏 | 奶牛 | 牛奶 | 42s | 260 起 |
| 猪栏 | 花猪 | 猪肉 | 58s | 320 起 |
| 羊栏 | 绵羊 | 羊肉 | 72s | 380 起 |

- 每栏最多 4 只，动物会在畜栏里来回走动；
- 同栏每多一只，买入价略涨；
- 初始送 1 只母鸡，其余需要花王都币买入。

## 3. 饲养

- 每只动物每轮消耗 1 份**饲料**；
- 饲料来自加工屋「配饲料」（玉米 2 + 小麦 1）；
- 没有饲料时可以花 55 王都币/份应急补买（比自己做贵）；
- 喂食后开始计时，产出完成后点畜栏收取；
- 收取后动物回到待喂食状态，不会饿死、不会掉健康。

## 4. 与餐厅联动

- 每种牧产**第一次收取**时写入 `profile.ingredientUnlocks`，餐厅营业随即无限供应对应原材料：鸡蛋、牛奶、猪肉、羊肉都按各自首次收取解锁；
- 解锁后即使把库存卖光，营业供应也不会回退；半成品与成菜仍必须现做；
- 因此牧场既是餐厅高价菜的原料来源，也是营业牧产菜式的解锁条件。

## 5. 与三消联动

- 牧场**首次收获**任意牧产后，自动解锁三消皮肤「牧场鲜货方块」；
- 该皮肤包含鸡蛋、牛奶、肉排、奶酪、饲料 5 个新方块精灵；
- 皮肤只改外观，不影响三消数值。

## 6. UI

- 顶部：返回 / 标题 / 王都币；
- 饲料条：显示库存饲料与应急价格；
- 2×2 畜栏：每栏显示动物、数量、状态、产出进度、买入按钮；
- 状态：待喂食 / 产出中 / 可收取 / 空栏；
- 底部提示：牧产进仓库 + 首次收获解锁营业供应与方块。

## 6. 存档

```ts
interface RanchSave {
  schemaVersion: 2;
  pens: Array<{ species: string; count: number; readyAt: number }>;
  totalProducts: number;
  totalFeeds: number;
  totalCoins: number;
  starterFeedGiven: boolean;
}
```

- key：`save:ranch`；v1 → v2 补 `starterFeedGiven`；
- 首次进入送 2 份饲料，避免 0 币 0 饲料时卡在第一步；
- 按真实时间产出，离线也会成熟；
- `readyAt: 0` 表示待喂食。

## 7. 文件结构

```
data/animals.ts      四种动物、产物、价格、产出时间
systems/ranch.ts     喂食 / 产出 / 收取 / 买动物 / 存档迁移
view/ranch-view.ts   畜栏、动物游走、状态与命中
game.ts              控制器与反馈
```

## 8. 合规

- 只做饲养与收集，无屠宰/血腥表现；
- 无真实货币、无内购、无抽卡；
- 不出现恋爱/情侣/交友文案。
