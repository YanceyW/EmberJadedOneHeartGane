# 甜品合成屋

## 1. 核心

合并相同甜品 → 解锁新甜品 → 完成订单 → 装饰店铺。

## 2. 循环

```
短：合并/收成（30 秒）
中：订单/图鉴/解锁（1–7 天）
长：店铺装饰/限定甜品/收集（7–30 天）
```

## 3. 棋盘

- 5×6 网格；
- 生成器每 N 秒产出基础物品；
- 拖拽合并相同 tier；
- 满格时提示出售/合并；
- 不设失败，只有效率。

## 4. 物品链

```
面粉 → 面团 → 饼干 → 蛋糕 → 婚礼蛋糕
糖 → 糖霜 → 马卡龙 → 甜品塔
莓果 → 果酱 → 派 → 莓果蛋糕
```

- DAG，无环；
- tier 1–8；
- 合成 2 个 → 1 个高级；
- 出售得星尘。

## 5. 订单

- 访客要 1–3 种甜品；
- 奖励星尘/装饰；
- 每日 3 个；
- 订单从已解锁物品生成；
- 可刷新 1 次。

## 6. 能量

- 上限 50；
- 合并消耗 1；
- 每 3 分钟恢复 1；
- 离线恢复（上限）；
- 不卖能量（首发）；
- 广告后置：自愿补充。

## 7. 图鉴

- 每解锁一个 tier 记录；
- 首次解锁给繁荣度；
- 不显示未解锁配方（只给提示）。

## 8. 店铺装饰

- 墙面/地板/柜台/招牌；
- 来自订单/繁荣度；
- 不影响数值；
- 双人共享。

## 9. 双人

- 同屏分区；
- 共享棋盘/订单；
- 一人合并、一人收成；
- 不实时联机。

## 10. 经济

- 星尘：出售/订单；
- 金币（游戏币）：装饰；
- 不内购；
- 广告后置。

## 11. UI

- 顶部：能量/星尘/订单；
- 棋盘居中；
- 底部：生成器/图鉴/装饰；
- 合成特效：糖霜/星光；
- 统一 design-system。

## 12. 存档

```ts
interface MergeSave {
  schemaVersion: number;
  board: (MergeItemRef | null)[];
  unlocked: string[];
  energy: number;
  energyUpdatedAt: number;
  orders: MergeOrder[];
  decorations: string[];
  stats: { merges: number; orders: number; maxTier: number };
}
```

## 13. 事件

- `merge`；
- `order_complete`；
- `energy_empty`；
- `decorate`；
- `duo_start/complete`。

## 14. 边界

- 棋盘满 → 提示；
- 能量为 0 → 等待/广告（自愿）；
- 离线能量恢复上限；
- 时钟回拨 → 单调时间；
- 存档损坏 → 重建。

## 15. 测试

- 合成链无环；
- 订单可完成；
- 能量恢复；
- 棋盘满处理；
- 双人输入；
- 存档 migration。

## 16. 风险

- 内容消耗 → 物品链 + 订单 + 装饰；
- 数值膨胀 → 指数成本 + 订单权重；
- 美术量大 → 图标 + 统一风格；
- 类目 → 休闲合成，无问题。
