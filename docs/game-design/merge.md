# 王都加工屋

> 状态：可玩原型（`src/games/merge`，分包 `merge`）。
> 两个页签：**合成台**（5×5 合并）与**原料间**（12 条中式半成品配方，含牧场饲料）。
> 存档 `save:merge`，排行榜 id `merge`。名字用「加工屋」，不再叫「合成屋」。

## 1. 核心

- **合成台**：点两个同等级物品合成上一级；链为莓果 → 果酱 → 蛋糕 → 宴席；「进货」花 6 王都币生成物品；加工单要成品，交付给王都币 + 繁荣度；二级以上成品可直接卖。
- **原料间**：把仓库里的作物变成半成品，产物进**王都仓库**（`profile.pantry`），厨房与点菜直接取用。

两个页签共用一份存档与王都币，不引入第二种货币。

## 2. 原料间（跨馆产业链）

| 配方 | 消耗 | 产出 | 王都币 |
|---|---|---|---|
| 磨面粉 | 小麦 ×2 | 面粉 ×1 | 0 |
| 碾米粉 | 水稻 ×2 | 米粉 ×1 | 0 |
| 压挂面 | 面粉 ×2 | 挂面 ×1 | 2 |
| 磨玉米面 | 玉米 ×2 | 玉米面 ×1 | 2 |
| 捣蒜蓉 | 大蒜 ×3 | 蒜蓉 ×1 | 2 |
| 蒸馒头 | 面粉 ×3 | 馒头 ×1 | 3 |
| 腌酸菜 | 大白菜 ×2 | 酸菜 ×1 | 3 |
| 熬豆沙 | 大豆 ×3 | 豆沙 ×1 | 3 |
| 烤面包 | 面粉 ×2 | 面包 ×1 | 2 |
| 点豆腐 | 大豆 ×2 | 豆腐 ×1 | 3 |
| 熬菌菇高汤 | 蘑菇 ×2 + 洋葱 ×1 | 菌菇高汤 ×1 | 3 |

- 仓库是农场 / 加工屋 / 餐厅共用的唯一库存；
- 完整链条：农场收小麦 → 磨面粉 / 蒸馒头 → 餐厅厨房备菜 → 点菜卖菜价；
- 缺料可以「补齐」：按缺口付 **卖价 × 3**，一定不划算，只是救急。

## 3. 合成台规则

- 5×5 网格，格子大小按屏幕自适应；
- 「进货」6 王都币随机放进一个空格（16% 直接给一级）；棋盘满时退币并提示；
- 点击选中、再点另一个同等级格子合成；不同等级则改选；
- 加工单 3 张循环（果酱 / 蛋糕 / 宴席），交付扣棋盘物品；
- 卖出会把二级及以上成品一次性换成王都币，用于给卡死的棋盘腾地方；
- 不设失败与体力，只有效率。

## 4. 数值

| 等级 | 物品 | 卖价 |
|---|---|---|
| 0 | 新鲜莓果 | 2 |
| 1 | 手作果酱 | 6 |
| 2 | 莓果蛋糕 | 18 |
| 3 | 王都宴席 | 42 |

加工单：果酱 ×2 → 40 币；果酱 + 蛋糕 → 74 币；蛋糕 + 宴席 → 168 币。

## 5. UI

- 顶部：返回、标题、王都币；下方是「合成台 / 原料间」分段控件；
- 合成台：5×5 棋盘 → 今日加工单 → 进货 / 交付加工单 / 卖出成品；
- 原料间：王都仓库（作物计数）→ 11 张配方卡（两列紧凑卡：产物、`持有/需要`、加工费、`制作` 按钮）→ 缺料时卡内显示「补齐 N 币」→ 链条示意；
- 短屏也无需滚动：11 张卡按两列排 6 行，卡高自适应；
- 高屏合成台底部补一排成品货架，避免大片留白；
- 统一纸雕 UI，物品画法在 `view/item-art.ts`。

## 6. 存档

```ts
interface MergeSave {
  schemaVersion: 2;
  cells: number[];      // 25 格：-1 空，0–3 等级
  orderIndex: number;
  totalMerges: number;
  totalOrders: number;
  totalCoins: number;
  totalCrafts: number;  // 原料间加工次数
}
```

- key：`save:merge`；
- v1 → v2：补 `totalCrafts: 0`；
- 排行榜分数 = 合成次数 ×20 + 订单 ×100 + 原料加工 ×30。

## 7. 边界

- 棋盘满 → 提示先合成或卖成品；
- 仓库材料不够 → 提示去农场种一点，不扣任何东西；
- 王都币不够付烤面包 → 直接拦截，不扣材料；
- 存档损坏 → 重建。

## 8. 测试

- 合成链只升一级、不同级不可合；
- 订单扣物品并轮换；
- 卖出只收二级以上；
- 配方材料/币不足时不可制作；
- 存档 migration。

## 9. 风险

- 内容消耗 → 物品链 + 加工单 + 原料间；
- 数值膨胀 → 卖价与订单固定，不随等级指数增长；
- 类目 → 休闲合成，无问题。
