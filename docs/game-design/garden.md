# 王都花园

> 状态：可玩原型（`src/games/garden`，分包 `garden`）。
> 原型规则：6 块花圃；9 种花（雏菊 45s → 荷花 220s）；种子花王都币；点生长中的花浇水一次，缩短 35% 时间；收获后花进**王都仓库·花卉**，可「一键收获 / 浇全部 / 卖花 / 交花单」。花单 6 个循环，给王都币+繁荣度。存档 `save:garden`（v2），离线按真实时间生长。排行榜 id `garden`。
>
> 本文第 3–8 节是长期设计（遗传/繁育/布置/双人），**当前原型只实现了「种 → 浇 → 收 → 花单 → 仓库」**，未实现的部分在每节开头标了「未实现」。

## 1. 核心

种花 → 浇水 → 开花 → 花单/收集 → （规划）繁育新品种 → （规划）布置花园。

> 与 [farm.md](./farm.md) 的分工：花园只做花卉，不产出食材；食材由王都农场负责。两边产出都进王都仓库，分类不同。

## 2. 循环

```
短：播种/浇水/收获（20 秒–3 分钟）
中：花单/收集（1–7 天）
长：（规划）花园布置/季节花
```

## 3. 基因（未实现，长期方向）

```ts
interface FlowerGenome {
  species: string;
  color: { h: number; s: number; l: number };
  shape: 'round' | 'star' | 'bell' | 'spade';
  petals: number;   // 5–12
  size: number;     // 0.8–1.2
  fragrance: number;// 0–1
  rarity: 1 | 2 | 3 | 4 | 5;
}
```

### 遗传

- 颜色：Lab 混合 + 变异（±5%）；
- 形状/花瓣：显隐基因 + 随机；
- 稀有度：父母均值 + 变异概率；
-  fragrance：均值 + 噪声；
- 所有随机 seeded。

### 表现

- 花色 → HSV 染色花瓣贴图；
- 花瓣数 → 程序化排布；
- 形状 → 预置轮廓；
- L-system 只用于装饰藤蔓，不每帧重算。

## 4. 生长

| 阶段 | 时间 | 操作 |
|---|---|---|
| seed | 0 | 播种 |
| sprout | 30s | 浇水 |
| bud | 2h | 施肥 |
| bloom | 4h | 收获 |

- 离线也生长（按时间戳）；
- 缺水会暂停，不死亡；
- 不惩罚玩家。

## 5. 订单（已实现：6 个循环）

- 6 个花单循环，例如「两色花束」「一束郁金香」；
- 需求显示 `持有/需要`，花直接取自王都仓库·花卉；
- 奖励王都币 + 繁荣度；
- 不做每日刷新、不做可刷新次数（避免刷单）。

## 6. 图鉴（部分实现）

- 收集册按「花卉」分页展示 9 种花；
- 首次收获给繁荣度；
- 不显示未发现的具体配方（只给提示）。

## 7. 花园布置（未实现）

## 8. 双人（未实现）

- 同屏分区；

## 9. 经济

- 王都币：订单/每日；
- 种子：订单/商店（游戏币，非内购）；
- 不卖稀有花；
- 广告后置：自愿加速生长。

## 10. UI

- 花园主视图（可缩放/拖动）；
- 底部：种子/工具/订单/图鉴；
- 开花特效：花瓣/星光；
- 统一 design-system。

## 11. 存档（v2）

```ts
interface GardenSave {
  schemaVersion: 2;
  plants: Array<{ flowerId: string; plantedAt: number; watered: boolean } | null>;
  plotsUnlocked: number;
  orderIndex: number;
  discovered: string[];
  totalHarvests: number;
  totalCoins: number;

```

- key：`save:garden`；
- **v2 起花园不再自带库存**：花直接进 `profile.pantry`（王都仓库·花卉）；
- v1 存档的 `inventory` 由 `legacyInventory()` 读出，进场时一次性并进仓库并改写存档（只搬一次）；
- 排行榜分数 `gardenScore = 收获朵数 × 10 + 累计收入`。

## 12. 事件

- `plant` / `water` / `bloom` / `harvest`；
- `breed`；
- `order_complete`；
- `duo_start/complete`。

## 13. 边界

- 离线时间过长 → 最多累计 24h；
- 时钟回拨 → 用服务器时间/本地单调时间；
- 花园满 → 提示收获/扩建；
- 存档损坏 → 备份 + 重建。

## 14. 测试

- 遗传分布 1000 次；
- 颜色混合边界；
- 离线生长；
- 订单可完成；
- 布局保存；
- 双人输入。

## 15. 风险

- 遗传太复杂 → 只做 4 个可见维度；
- 美术量大 → 花瓣模板 + 染色；
- 离线作弊 → 服务端时间校验（排行榜）；
- 类目 → 休闲种植，无问题。
