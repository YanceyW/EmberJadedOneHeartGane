# 王都经济循环：一条产业链，一种货币

> 目标：让「王都币」在多个休闲玩法之间流动，形成可持续但不肝的循环。
> **只有王都币**：没有第二种货币、没有体力、没有抽卡、没有内购。
> 决策记录：[ADR-0023](../decisions/ADR-0023-warehouse-and-restaurant-three-lines.md)

## 1. 一句话

**农场种粮 → 加工屋磨面/配饲料 → 牧场产肉蛋奶 → 餐厅组合做菜 → 点菜卖高价 → 王都币 → 买种子 / 买鱼 / 买外观。**

三消是稳定的快币源；农场、加工屋、牧场、餐厅是同一条产业链的四段，靠**王都仓库**串起来，不是四个独立小游戏。

## 2. 王都仓库（唯一库存）

- 存在 `profile.pantry`，全馆读写同一份：**基础 / 作物 / 花卉 / 牧产 / 半成品 / 茶饮 / 成菜**都在这里；
- 货物目录与价格只在 `src/shared/content/ingredients.ts` 定义（89 种）：
  - 基础 1：清水 1（餐厅无限供应，不进仓库）
  - 作物 18：小白菜 12 → 葡萄 58（卖价）
  - 花卉 9：雏菊 18 → 荷花 104
  - 牧产 4：鸡蛋 46 / 牛奶 58 / 猪肉 88 / 羊肉 96
  - 半成品 14：饲料 26 / 挂面 26 / 酸菜 40 / 菌菇高汤 44 / 猪肉高汤 70 → 奶酪 64
  - 茶饮 10：米浆 16 → 荷花茶 98
  - 成菜 33：阳春面 35 / 萝卜糕 44 / 蔬菜焖饭 43 → 砂锅全家福 128（仓卖价 = 菜价 × 0.4）
- 每种上限 999，避免数值爆炸；
- 花园 v1 存档里自带的库存、农场 v1 存档里的作物都会在进场时搬进仓库（只搬一次）。

### 仓库面板（库房）

街区西街的**王都仓库**是设施建筑，点开就是仓库面板：

- 7 个分页（基础 / 作物 / 花卉 / 牧产 / 半成品 / 茶饮 / 成菜），每格显示图形 + 数量 + 单价；
- 点格子勾选要卖的，底部实时显示「已选 N 种 · M 件 · +X 王都币」；
- `全选本类` / `清空` / `卖出选中` 三个动作，卖完立即进币并写存档；
- 顶部显示库存总价值与本类小计，方便判断「留着做菜」还是「直接卖」。

### 采购补齐

缺料时不必等作物成熟，可以直接用王都币补齐：

- **采购价 = 卖价 × 3**（取 5 的倍数）；
- 入口：加工屋原料间的「补齐」、牧场没有饲料时的「应急补买」；
- 采购一定不划算（价格不变量由测试锁定），它只是「现在就想玩」的救急通道。

## 3. 各场馆职责

| 场馆 | 职责 | 主要产出 | 主要消耗 |
|---|---|---|---|
| 王都三消 | 快速一局、稳定币源 | 王都币、繁荣度 | 闯关 3 分钟 / 无时间限制随时退出 |
| 王都农场 | 食材生产、离线成长 | 18 种作物进仓库、订单币 | 种子、开地 |
| 王都加工屋 | 合并甜品 + 半成品加工 | 加工单币、成品卖价、14 种半成品 | 进货、合成次数、加工费 |
| 王都牧场 | 饲养动物、产肉蛋奶 | 4 种牧产进仓库、繁荣度 | 饲料（或应急王都币）、买动物 |
| 王都餐厅 | 备料 / 点菜 / 营业 | 菜价营业额、繁荣度 | 原料（备料台/灶台）、成品（点菜）；营业不耗仓库 |
| 王都花园 | 花卉种植与浇水 | 9 种花进仓库、花单币、繁荣度 | 花种 |
| 王都水族馆 | 养鱼 / 喂食 / 访客 | 8 种鱼、泡泡币、访客订单币 | 买鱼、鱼食 |
| 王都仓库 | 资产总览与出口 | 卖货得币 | 各种货物 |
| 王都小铺 | 外观与皮肤 | — | 建设、装扮、天气（免费）、风格、图标、方块皮肤 |
| 每日委托 | 每天 3 单消耗囤货 | 王都币、繁荣度、连续天数 | 指定货物（点「交付」才扣） |

### 不重叠原则

- **农场 = 食材**；**花园 = 花卉**，不产出食材；
- **加工屋 = 合并 + 半成品**：莓果 → 果酱 → 蛋糕是合并玩法；小麦 → 面粉 → 挂面/馒头、玉米 + 小麦 → 饲料是半成品加工；
- **牧场 = 肉蛋奶**：饲料换鸡蛋/牛奶/猪肉/羊肉，四种产物首次收取后都解锁营业对应原材料；
- **餐厅 = 成菜**：备料台 + 3×3 灶台吃原料、点菜吃成品、营业只吃「清水 + 已解锁 crop/flower/ranch」；半成品与成菜必须现做；
- **餐厅每日目标**：点菜上 8 道领 150 王都币 +3 繁荣，跨天重置；营业最佳成绩计入餐厅排行榜；
- **水族馆 = 鱼**：不抽卡、不卖真实货币；
- **方块皮肤 = 纯外观**：三消数值与皮肤无关。

## 4. 产业链

```
农场（小麦 2 / 玉米 2，30–75 秒）
   │ 收进王都仓库
   ▼
加工屋·原料间「磨面粉」/「配饲料」
   │ 面粉 1 / 饲料 1
   ▼
牧场（喂饲料）→ 鸡蛋 / 牛奶 / 猪肉 / 羊肉
   │ 收进王都仓库
   ▼
餐厅·备料台 + 3×3 灶台（摆图案 + 看火）
   │ 面粉 + 牛奶 = 馒头；番茄 + 鸡蛋 = 番茄炒蛋；高汤+挂面+鸡蛋 = 什锦汤面
   ▼
餐厅·点菜「上菜」→ 40–350 王都币 + 繁荣度
```

- 菜价始终高于食材卖价之和，所以**走产业链比直接卖作物更赚**；
- 直接卖作物/花卉仍然保留（仓库面板），作为「不想做菜时」的保底出口；
- 半成品卖价低于原料之和：加工的意义是「做菜」，不是「倒卖」；
- 成菜仓卖 = 菜价四折且低于食材之和，堵住「做了再卖」的套利。

## 6. 每日委托

- 每天 3 单，按日期确定性抽取（同一日期同一结果，不重复挑战刷新）；
- 池子示例：面馆补货（挂面 + 酸菜 + 番茄）、花店补花（雏菊 + 郁金香）、茶馆要茶（两款花茶）；
- **必须手动点「交付」**才扣货结算，不点就一直留着；
- 3 单全清：额外 `+120 王都币 / +3 繁荣度`，并累计连续天数；
- 委托不生成随机高价，价格 = 货物卖价 × 数量 + 固定加成，避免刷单套利。

## 7. 物价与产出原则

- 种子成本 < 作物售价，但受生长时间限制（20–120 秒）；
- 订单/菜品奖励 > 直接卖原料，鼓励加工与组合；
- 外观价格高于一次订单，形成中长期目标；
- 价格集中在 `src/shared/content/ingredients.ts`（货物）、`menu.ts`（菜价）、`daily-orders.ts`（委托）、`src/lobby/shop.ts`、`shared/content/tile-skins.ts`、各游戏 `data/`；
- 不设置付费加速、付费补体力；
- 不做每日强制打卡惩罚，离线最多累计 24 小时。

## 8. 反刷与边界

- 农场/花园按真实时间生长，水族馆泡泡币按真实时间积累，不按点击次数；
- 三消「无时间限制」**不设步数、不设时限**，但奖励按分数封顶 60 币/局，长局不会无限印钱；
- 餐厅营业无固定时长，但受 2 个灶台、3 个客人位、最多 5 道订单与焦糊品质限制，收入不会无限膨胀；
- 收获/订单/上菜/出售/收币/交付都写本地存档，切后台保存；
- 时钟回拨：以 `Date.now()` 与单调计时结合，发现回拨只提示不惩罚；
- 单一食材 999 上限；
- 委托按日期确定性生成，不生成随机高价订单；
- 不做玩家间交易、拍卖行、赠送。

## 9. 排行榜只展示

- 排行榜（闯关 / 无尽 / 农场 / 牧场 / 花园 / 加工屋 / 水族馆 / 餐厅）**只展示名次与分数，不发王都币、不发繁荣度**；
- 分数一律取该玩家该子项的最高值；
- 大数字统一走 `shared/format.ts`：1.2万 / 3.6亿，避免榜单被长数字撑爆。

## 10. 合规边界

- 个人主体、休闲类目；
- 无 UGC、聊天、陌生人社交、公会；
- 无抽卡、盲盒、内购、真实货币；
- 广告只做自愿激励，失败不影响游戏；
- 不收集头像/昵称/手机号，只用 openid；
- 不出现恋爱/情侣空间/交友文案；
- 餐厅/农场只做「做菜、种地、订单」，不做真实货币交易或雇佣关系叙事。
