# 术语表

| 术语 | 含义 |
|---|---|
| 主包 | 启动即加载的包，含大厅/核心/共享 |
| 分包 | 按需加载的游戏包 |
| 独立分包 | 可独立运行的分包；本项目不用 |
| GameDefinition | 游戏对外的统一契约 |
| GameContext | 运行时注入给游戏的能力集合 |
| GameInstance | 一局游戏的实例 |
| Scene | 场景（大厅/游戏/弹窗） |
| Design Token | 颜色/圆角/字号/动效等统一变量 |
| ProceduralCache | 程序化生成结果的缓存 |
| Asset Library | 资产清单/加载/复用/释放 |
| Manifest | 资产清单 |
| Atlas | 图集 |
| Meta | 大厅层的长期进度/收集/经济 |
| Duo Mode | 同屏双人 |
| Daily Challenge | 每日挑战 |
| Seed | 随机种子 |
| RNG | 随机数生成器 |
| ADR | 架构决策记录 |
| IAA | 应用内广告（激励视频等） |
| openid | 微信用户在本小游戏的唯一标识 |
| 冷启动 | 首次打开到大厅 |
| DPR | 设备像素比 |
| 9-slice | 九宫格拉伸 |
| LRU | 最近最少使用淘汰 |
| Headless | 无渲染的逻辑模拟测试 |
