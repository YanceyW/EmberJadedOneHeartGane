# 内容管线

## 1. 内容类型

| 类型 | 形式 | 校验 |
|---|---|---|
| 关卡 | JSON + seed | 可解性/目标/障碍 |
| 花卉 | genome + 表 | 颜色/形状/稀有度 |
| 鱼类 | genome + 表 | 纹理/稀有度 |
| 物品链 | DAG | 无环/引用完整 |
| 订单 | 模板 + 权重 | 奖励/可完成 |
| 装饰 | 表 + 图集 | 尺寸/锚点 |
| 每日 | 种子 + 规则 | 可复现 |
| 赛季 | 配置 | 时间/奖励 |

## 2. 生产流程

```
设计 → 数据表/JSON → schema 校验 → 本地预览
→ 平衡测试（headless）→ 真机 → 入 content → 版本号+1
```

## 3. 内容目录

```
src/games/<id>/data/
  levels/
  items/
  flowers/
  fish/
  orders/
  decorations/
  season.json
```

## 4. 校验

- JSON schema；
- ID 唯一；
- 引用完整；
- 数值范围；
- 可解性（三消）；
- 经济模拟（合成/花园）；
- 包体影响；
- 版本递增。

`npm run validate:content` 必须通过。

## 5. 平衡

- headless 跑 1000 局；
- 目标胜率：三消 60–75%，花园/合成/水族馆无硬失败；
- 经济不崩：产出/消耗比 0.9–1.1；
- 新玩家 5 分钟内看到第一个奖励；
- 7 天留存目标用埋点验证。

## 6. 赛季

- 4 周一季；
- 主题：花/鱼/甜品/装饰；
- 赛季内容独立配置，可回滚；
- 赛季结束保留收集；
- 不搞绝版焦虑。

## 7. 发布

- 内容版本号；
- 灰度/远程配置；
- 出问题回滚内容配置；
- 不热更代码（审核约束）；
- 数据兼容旧存档。
