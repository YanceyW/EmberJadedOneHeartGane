# 路线图

> 每个阶段都有退出标准；不达标不进入下一阶段。

## 阶段 0：清理与骨架（构建/无头冒烟已完成）

- 删除模板；
- 初始化 git/TS/ESLint/Prettier/Vitest；
- 构建/`game.json`/体积检查；
- 大厅可启动，四款场馆「即将开放」；
- 云离线降级；
- README/docs/AGENTS。

**退出**：主包 ≤3MB；build/test/smoke 通过；开发者工具真机确认由你在本机完成。

## 阶段 1：核心运行时 + 三消垂直切片（进行中）

- 场景/渲染/输入/音频/资源/存档/云/UI（基础版已完成）；
- 三消 10 关 + 3 分钟倒计时 + 节奏加成 + 滑动交换 + 星级 + 每日挑战 + 存档迁移（已完成）；双人接力原型（待做）；
- 云登录/存档/排行榜；
- 程序化 vs 位图对比；
- 本地 AI 小批量资产；
- 技术 Spike 决策门。

**退出**：真机可玩；主包 ≤3MB；三消 ≤2MB；云可用；视觉验收。

## 阶段 2：花园 + 合成

- 花园遗传/离线成长/订单/布置/双人浇水；
- 合成链/订单/能量/经济/双人订单；
- 大厅四入口 + 进度；
- 每日委托/收集册/王都币/繁荣度。

**退出**：三款可玩；离线/弱网/切后台稳定；存档迁移通过。

## 阶段 3：水族馆 + Meta 完整化

- 水族馆繁育/鱼纹/造景/访客订单/双人喂鱼；
- 双人广场；
- 排行榜/周榜/分享卡片；
- 新手引导/设置/隐私/删除数据；
- 全量无头 + 真机矩阵。

**退出**：四款可玩；无阻塞 bug；包体 ≤28MB；类目确认。

## 阶段 4：合规与发布

- 名称/类目/备案/隐私/适龄；
- 审核；
- 生产云/监控/备份；
- 发布。

**退出**：审核通过、备案完成、监控正常。
