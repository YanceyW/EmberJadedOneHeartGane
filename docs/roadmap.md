# 路线图

> 每个阶段都有退出标准；不达标不进入下一阶段。

## 阶段 0：清理与骨架（构建/无头冒烟已完成）

- 删除模板；
- 初始化 git/TS/ESLint/Prettier/Vitest；
- 构建/`game.json`/体积检查；
- 大厅可启动（阶段 0 时场馆均为「即将开放」占位）；
- 云离线降级；
- README/docs/AGENTS。

**退出**：主包 ≤3MB；build/test/smoke 通过；开发者工具真机确认由你在本机完成。

## 阶段 1：核心运行时 + 三消垂直切片（进行中）

- 场景/渲染/输入/音频/资源/存档/云/UI（基础版已完成）；
- 三消 10 关 + 3 分钟倒计时 + 节奏加成 + 滑动交换 + 星级 + 存档迁移（已完成）；双人接力原型（待做）；
- 三消双模式：闯关 + 无时间限制（不计时、不限步数）；方块皮肤商店；排行榜按模式拆分（已完成）；
- 云登录/存档/排行榜；
- 程序化 vs 位图对比；
- 本地 AI 小批量资产；
- 技术 Spike 决策门。

**退出**：真机可玩；主包 ≤3MB；三消 ≤2MB；云可用；视觉验收。

## 阶段 2：农场 + 花园 + 加工屋（已完成）

- 农场：18 种作物/9 块地/8 个订单/离线成长（可玩）；
- 花园：9 种花/浇水/6 个花单/离线成长（可玩，库存进仓库）；
- 加工屋：5×5 合并/加工单/进货/卖成品 + 原料间 12 条半成品配方（可玩）；
- 王都仓库：**全馆唯一库存**（作物/花卉/半成品/茶饮/成菜），库房设施 + 多选卖出 + 采购补齐；
- 每日委托：每天 3 单，点「交付」才扣货，全清有额外奖励与连续天数；
- 大厅入口 + 进度；
- 经济循环见 [game-design/economy-loop.md](./game-design/economy-loop.md) 与 [ADR-0023](./decisions/ADR-0023-warehouse-and-restaurant-three-lines.md)。

**退出**：三款可玩；离线/弱网/切后台稳定；存档迁移通过。

## 阶段 3：水族馆 + 餐厅 + Meta 完整化（基本完成）

- 水族馆：8 种鱼/喂食/泡泡币/访客订单（可玩原型）；繁育/鱼纹/造景后续；
- 餐厅：**备料台 + 3×3 灶眼 / 点菜 / 无时限营业** 三条线（可玩原型）；
- 牧场：鸡/牛/猪/羊四栏、饲料饲养、肉蛋奶进仓库（可玩原型）；
- 三消联动：牧场首次收获解锁「牧场鲜货方块」皮肤；
- 双人广场（待做）；
- 排行榜（只展示，不发币）/分享卡片；
- 新手引导/设置/隐私/删除数据；
- 全量无头 + 真机矩阵。

**退出**：至少四款可玩（含农场原型）；无阻塞 bug；包体 ≤28MB；类目确认。
