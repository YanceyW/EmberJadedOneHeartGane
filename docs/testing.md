# 测试策略

## 1. 金字塔

### 单元测试（Vitest）

- 棋盘/匹配/消除/重排；
- 合成链/订单/经济；
- 遗传/颜色/稀有度；
- 鱼纹/鱼群；
- 存档 migration；
- RNG 可复现。

### 无头模拟

- 固定 seed 跑 1000 局；
- 检查：不崩溃、不死锁、资源不变量、经济不崩；
- 双人输入序列模拟；
- 每日种子一致。

### 快照

- 关键 UI 在 750×1334 / 1080×2400；
- 安全区/刘海/底部横条；
- 颜色/布局回归。

### 真机

| 设备 | 目的 |
|---|---|
| 低端安卓 | 30fps/内存 |
| 中端安卓 | 60fps |
| iPhone SE | 小屏/安全区 |
| iPhone 15 | 高 DPR |

### 弱网/离线

- 飞行模式启动；
- 断网重连；
- 切后台 10 分钟；
- 云函数超时；
- 存档冲突。

### 性能

- 冷启动到大厅；
- 进入游戏；
- 每帧耗时；
- 内存峰值；
- 包体。

### 无头运行时冒烟

`npm run smoke` 用 mock `wx`/canvas 加载 `dist/game.js`，模拟一次大厅点击和一次游戏内点击，检查：

- 启动不抛错；
- `game.json` 分包配置存在；
- 分包入口能注册；
- 大厅与三消场景能渲染。

## 2. 门禁

```bash
npm run typecheck
npm run lint
npm run test
npm run build
npm run size
npm run smoke
```

或一次跑完：

```bash
npm run verify
```

## 3. 测试数据

- 固定 seed；
- 最小/最大/边界；
- 损坏存档；
- 旧版本存档；
- 缺资源；
- 空内容。

## 4. 缺陷等级

| 等级 | 定义 | 处理 |
|---|---|---|
| P0 | 崩溃/丢档/无法进入 | 立即修 |
| P1 | 主流程卡死/严重卡顿 | 发布前修 |
| P2 | 表现/文案/小布局 | 可排期 |
| P3 | 建议 | 记录 |

## 5. 发布前

- 全量回归；
- 真机矩阵；
- 弱网/离线；
- 包体/性能；
- 合规检查；
- 回滚演练。
