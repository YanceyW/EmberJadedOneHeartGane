# 测试策略

## 1. 金字塔

### 单元测试（Vitest）

- 棋盘/匹配/消除/重排；
- 合成链/订单/经济；
- 遗传/颜色/稀有度；
- 鱼纹/鱼群；
- 存档 migration（含 `stardust → coins`、Profile v2）；
- 王都币获取/消费/外观拥有状态；
- 2.5D 城景投影、建筑深度排序与命中；
- 三消王都币奖励档位/首通/三星/无尽封顶；
- 三消双模式最高分分开合并、方块皮肤购买/装备；
- 农场 18 种作物与 8 个订单循环；牧场四栏饲养/产出/收取/买动物；花园浇水/花单（存档 v2 迁移）；加工屋合并/加工单/卖成品 + 原料间 12 条配方与补齐；水族馆喂食/产币/访客订单；餐厅 3×3 灶眼图案、2–4 输入、品质结算、无时限营业、打烊中/完美打烊、负净收入与钱包 floor 0、食材解锁与横向供应轨（营业不读写 pantry）；
- 王都仓库：农场/花园收获进 `profile.pantry`，加工屋与餐厅从同一份仓库读写（含原子扣除与 999 上限）；仓库多选卖出与采购价（卖价 ×3，取 5 倍数）；
- 经济不变量：组合/加工产出仓卖 < 原料和、菜价 > 食材和、成菜仓卖 = 菜价四折且 < 食材和、全采购做菜必亏；
- 每日委托：同日确定性抽取、不点「交付」不扣货、全清奖励与连续天数；
- 灶台：图案匹配（相邻/三连/L/方块/T/旋转镜像）、同材料不同图案、2→3→4 升级、焦糊品质与收取；
- 建议：灶台续接优先、客人订单路径、成品预计收入；
- 存档：餐厅 v3→v5（备料台/灶台/旧 combo-N 映射/每日点菜目标）；
- 视图烟测：餐厅三页（含每日目标、空灶 ghost、横向供应轨与锁定项）+ 牧场在 750×1334 / 750×1624 下渲染不抛错；
- 控制器拖放：原料→备料台→灶眼；断料建议过滤、每日目标领取、焦炭回收有纯逻辑测试；负结算不会把王都币扣成负数；
- 唯一名字候选、校验与改名；
- RNG 可复现。

### 无头模拟

- 固定 seed 跑 1000 局；
- 检查：不崩溃、不死锁、资源不变量、经济不崩；
- 双人输入序列模拟；
- 滑动手势方向 / 阈值；
- 节奏窗口与倍率封顶；
- 倒计时递减、警告阈值与归零判定；
- 死局重排与无尽步数扣减。

### 快照

- 关键 UI 在 750×1334 / 1080×2400；
- 安全区/刘海/底部横条；
- 颜色/布局回归。

### 真机

| 设备 | 目的 |
|---|---|
| 低端安卓 | 30fps/内存 |
| 中端安卓 | 60fps |
| iPhone SE | 小屏/安全区 |
| iPhone 15 | 高 DPR |

### 弱网/离线

- 飞行模式启动；
- 断网重连；
- 切后台 10 分钟；
- 云函数超时；
- 存档冲突。

### 性能

- 冷启动到大厅；
- 进入游戏；
- 每帧耗时；
- 内存峰值；
- 包体。

### 无头运行时冒烟

`npm run smoke` 用 mock `wx`/canvas 加载 `dist/game.js`，模拟大厅点击与三消滑动
（`touchstart → touchmove → touchend`，每次留出动画时间），检查：

- 启动不抛错；
- `game.json` 分包配置存在；
- 分包入口能注册；
- 大厅与六个游戏场景能渲染；
- 平铺王都建筑可点、可进入三消；六个分包入口都能注册；西街仓库可点开面板；
- 三消先选模式再滑动，覆盖闯关开始链路；
- 滑动能触发消除并产生合成音效；
- 农场可播种/收获/交订单/卖作物；
- 天气/节日风格切换后不崩溃；
- 纯手势路径也能完成音频解锁；
- 胶囊安全区不遮挡自绘 UI（开发者工具/真机）；
- 短屏（iPhone SE）下半屏不溢出。
